## Reported evidence

Pre-existing, live for all tenants (SA-681 confirmed by read). The legacy branch of reconcileOrderDraftInvoice rebuilds the OLDEST open partial draft invoice to the FULL order while the other partial invoices still bill, so the order is billed twice. Triggers: Mark Delivered, undelivered edits, the merge winner. Fix in progress: PC builder, branch fix/split-invoice-double-bill.
