## Reported evidence

handleScanned in the driver at-stop adjust screen adds a scanned product by hand: for a boxed product it does boxes + 1 and recomputes qty as boxes * unitsPerBox + pieces, otherwise qty + 1. It never asks which level the scanned code belongs to, so a code that identifies a unit or a pallet still adds a box. The scan rule (SA-580) resolves the level from the scanned code; this handler should call that scan-level resolver instead of its own arithmetic. Follow-up to SA-595. Source: SA-595c, board #2554 comment 5896990545.
