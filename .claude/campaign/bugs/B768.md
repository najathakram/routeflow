## Root cause

From the Opus review of #1283 (fleet lead relay 2026-09-23); verified on origin/master 2ed80789: report-addon-gate-blast-radius.mjs:56 uses `const databaseUrl = process.env.DATABASE_URL` directly. scripts/lib/railway-db-url.mjs documents that under `railway run --service postgres` DATABASE_URL is the unreachable *.railway.internal host (proxy vars must win). So the owner's blast-radius run — the evidence CLAUDE.md requires before ANY @RequireAddon gate flips dark→enforced — fails with ENOTFOUND. Fix: resolveDatabaseUrl(process.env, { requireProxy: true }) + redactUrl, as t6-null-rows-report.mjs does. SWEEP (18 scripts already use resolveDatabaseUrl; these read process.env.DATABASE_URL without it): owner-run READ-ONLY prod reports, same defect, fix in the same PR — report-addon-gate-blast-radius.mjs, report-receiving-unit-drift.mjs, report-train4-damage.mjs, prod-readonly-audit.mjs, audit-tenant-entitlements.mjs, propose-pack-sizes.mjs; older .js checkers: check-customer-tenants.js, check-tenant-logo.js, check-discrepancies.js, finance-audit.js, sales-gap-analysis.js. WRITERS with the same pattern (repair-receiving-units.mjs, repair-escaped-entities.mjs, backfill-tobacco-category.mjs, tidy-regulated-categories.mjs, backfill-*.js, merge-*.js, fix-*.js, migrate-legacy-users.js, import-zoho.js, seed-irs-categories.js, invalidate-tenant-pdf-cache.js, apply-rls.js, create-super-admin.js, reset-super-admin.js) — list only, a separate decision; the destructive/QA scripts (nuke-*, DANGER-*, wipe-*, cleanup-qa-data, qa-*, ux-audit-*) are out of scope and must never be pointed at prod (CLAUDE_SESSION_PREAMBLE). #1283 carries the same defect and is being fixed in-PR.
