## Summary

SCOPE EXTENDED AGAIN (lead, 2026-10-02, source: the #3025 Opus review, #2554 latest): beyond PLAN_GATE, the meter keys and READ_ONLY, add these hand-typed web codes to API_ERROR_CODES and the api parity file: INSUFFICIENT_STOCK, PLAN_GATE_UNAVAILABLE, the five INLINE_RETURN_* codes, UNIT_AWARE_LINE, MERGE_PACK_MISMATCH, ORDER_CHANGED_DURING_EDIT, CONCURRENT_UPDATE, MERGE_IN_PROGRESS, LOCK_UNAVAILABLE, PO_ALREADY_BILLED, BILL_EXCEEDS_PO, INVOICE_HAS_UNSPENT_CREDIT, HANDOFF_CODE_INVALID. Register each in packages/types/api/error-codes.ts and the api parity file/spec and have the web import them (L-072).
