## What this feature is for

Context: Import · API batch invoice scanning → duplicate-match. This is part of the F44 batch ("Batch-import silently drops the supplier-invoice duplicate c…") — see the batch theme in the hunt digest for the surrounding feature's purpose.

## Root cause

Batch-import silently drops the supplier-invoice duplicate check when the scanned date is unparseable

Symptom / evidence: An invalid extracted invoiceDate nulls the date, kills the fuzzy supplier+date+total branch and classifies the scan CLEAN, so a numberless invoice can post a second vendor bill.

Files implicated: apps/api/src/import/batch-import.service.ts, apps/api/src/import/duplicate-match.service.ts, apps/api/src/vendor-bills/vendor-bills.service.ts.
