# B842 · Past recurring cycles of box-intent, category-taxed template lines wrote box counts as units to the regulated ledger, under-reporting filed units and levy 12x

## Root cause

Fleet lead relay 2026-09-24, from SA-135b (#1330 / B646 PASS at 09fa9253). Before #1330, every cycle of a recurring template line that was box-intent AND category-taxed stored the box count in the pieces column, so its regulated-ledger SALE rows carried qty-in-boxes as units (e.g. 6 where 72 pieces were sold): a 12x UNDER-report of units, and of the per-piece levy, in periods already filed. #1330 fixes it going forward (the subtotal is unchanged; the per-piece levy on those lines rises 12x to the correct figure). This record covers the PAST-period remedy only.

## Fix approach and UX

Size it first with #1330's read-only report (per-tenant units delta; the levy delta per cycle is being added), run on test tenants locally by F2 and on prod only by the owner. Any correction script follows the B681/SA-134 gates (dry run first, content-hashed plan, guard sha, fresh backup, assertTestTenant or live-tenant override with type-back).
