## Reported evidence

The panel, its count and the lane PR chip only include PRs whose state is open or draft, but the domain PRState also has ready (approved, CI green, mergeable clean), which waste.ts isOpen counts. A PR that is ready to merge therefore disappears from the panel, the count and the lane chip: wrong status for exactly the PRs nearest to merging. Repro: a fixture PR with review approved, ci green, mergeable clean renders in none of those. Fix: include ready in both filters, with a test (one line each).
