## Reported evidence

CreateSaleDto declares an undecorated idempotencyKey?: string (#3211). The api compiles to ES2023 with class-field semantics, so every transformed instance gets an own undefined idempotencyKey property, and the global ValidationPipe (whitelist + forbidNonWhitelisted) rejects it even when the client sends no such field. Repro: ValidationPipe.transform({customerId, items: []}, CreateSaleDto) returns 'property idempotencyKey should not exist'. Seen on the local stack built from the production Dockerfile (e2e 54 New sale).
