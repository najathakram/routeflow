## Root cause

Hunt B1 (fleet lead relay; low/informational). Verified on origin/master 2ed80789 (2026-09-23). startedAt is only written on the IN_PROGRESS transition (:1492); COMPLETED sets completedAt (:1493) with no startedAt backfill. forbiddenRunTransition permits SCHEDULED→COMPLETED (documented operator backfill), and updateStopStatus can SKIP every stop while the run is still SCHEDULED, so a skip-all run completes with startedAt null. API-only (the UI gate refuses). Fix: backfill startedAt = completedAt when null on completion.
