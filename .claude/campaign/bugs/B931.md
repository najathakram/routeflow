## Reported evidence

The preflight aborts when it counts more than 6 build-tool processes, which includes long-lived turbo daemon, docker and tsc --watch processes. At load1 2.3 on 10 cores it counted 8-18 and aborted run 4. Fix: key on load vs cores (for example load1 above 0.9 x ncpu over two samples), exclude idle daemons and watchers, or add a lead-set args.maxBuildProcs. Filed from the docs session via Mac Lead.
