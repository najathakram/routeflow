## Root cause

Fleet lead relay, 2026-09-23. Verified on origin/master 5ae97db7. resolveDatabaseUrl(env, { requireProxy }) skips the DATABASE_URL fallback when requireProxy is true (:28), but the single throw at :29-31 always reads 'No DATABASE_URL and missing Railway variables: … — run under railway run --service postgres or set DATABASE_URL'. Under requireProxy (writers per B768/B798, and prod-migrate), setting DATABASE_URL is NOT accepted, so the advice sends the operator the wrong way. Fix: branch the message on requireProxy (name only the missing RAILWAY_TCP_PROXY_*/POSTGRES_* vars and say DATABASE_URL is deliberately ignored), with a spec on both messages. No owner yet.
