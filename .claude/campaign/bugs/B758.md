## Root cause

Found by the Opus review of #1275 (fleet lead relay 2026-09-23); pre-existing, verified on origin/master 2ed80789: the buyer invoice line meta renders `{Number(item.qty)} x $${Number(item.unitPrice).toFixed(2)}` (:303-305). On a units_v1 line qty is stored in BASE PIECES while unitPrice is per unit, so a 3-Case line (12/case at $73.33) reads '36 x $73.33' — a buyer's own multiplication gives $2,640 against a real line of $220. Legacy boxed lines (qty = pieces, price per box) mislead the same way. Customer-facing; units-gating display. Built by R-ui in ONE mobile sweep PR with B757, B759 and a #1275 wiring pin.
