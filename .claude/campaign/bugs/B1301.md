## Reported evidence

Run on the Windows PC from a builder worktree (2026-11-09, node gate.mjs --json out.json via heavy-slot): packages-build, commitlint, prettier, tsc:apps/api, lint:apps/api, jest:apps/api, census:unit, census:repo-truth and size-ratchet each fail in 3-6 ms with exit 127 and the step tail 'spawn npx ENOENT' (npx, npm and commitlint resolve only as .cmd shims on Windows, and child_process.spawn without a shell cannot run them). Only node and git steps run (clean-tree, signature-scan, risk-class), so a Windows run is a false all-red gate: it hides real results. Operators run the gate commands by hand meanwhile. Fix idea, not done tonight: resolve the .cmd shim on win32 (npx.cmd) or pass shell:true only for win32 with the argv still fixed; add a unit test with a stubbed platform. Found by the bug-swarm lane while gating the C-1b branch.
