## Reported evidence

Live P1: .editorial-reveal sections (9 capability cards, section headings, wholesale-extras) never reached opacity 1 after scroll on /, /product, /wholesalers — CSS never declared an explicit revealed-opacity rule, only the reveal-pending=0 rule, relying on an implicit cascade fallback that failed in production. Separately, 4 text roles measured below WCAG AA: the operation-story widget heading (dark navy on dark navy, 1.09-1.61:1), the purple AI-scan card heading+paragraph (1.33-1.61:1), the --g-soft caption token (3.58:1), and the difference-section intro paragraphs (1.63:1) -- all traced to same-specificity CSS rules whose winner depended on stylesheet import/chunk order rather than being deterministic.
