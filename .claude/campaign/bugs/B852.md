# B852 · Invoice prefix and payment-due days in Settings → Invoicing never save

**Location** `apps/web/app/(dashboard)/settings/page.tsx InvoicingTab (~2422) · apps/api/src/system-config/settings.controller.ts PATCH allowlist` · **Severity** medium · **Batch** F29 · **State** queued

## Summary

Two dead controls on Settings → Invoicing: 'Invoice Number Prefix' and 'Payment Due Days' are sent to PATCH /settings but never persisted (zero API references), so both blank on reload. Correction to the filed evidence: the tenant DOES have a working default-terms setting — the tab's 'Payment Terms' select persists as invoice.defaultTerms via PATCH /settings/invoice (settings.controller.ts updateInvoiceSettings); only the prefix and due-days inputs are dead. The prefix's real home would be the numbering card, which has its own gap (B861).

The Invoicing tab sends invoicePrefix and paymentDueDays to PATCH /settings, but neither field is in the allowlist or returned by GET, so both blank on reload.
