## Reported evidence

businessName (tenant-controlled, TenantConfig.businessName) is interpolated directly into the email Subject header with no CRLF stripping -- a tenant setting their business name to a string containing CR/LF could inject additional email headers via the subject line, depending on how far upstream (nodemailer/Resend) sanitizes it. Separately, the plain-text alternative is built by regex-stripping HTML TAGS from the already-escaped html body without decoding entities back -- an escaped ampersand (rendered as the HTML entity in the html body) shows up literally as that entity text in the plain-text version instead of the real character.
