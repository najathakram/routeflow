## Reported evidence

activateManualSubscription writes periodEnd = now + billingPeriodDays but never sets TenantSubscription.cycle, so the schema default MONTHLY stays even for a 365-day payment; rollCycles then advances such a period by +1 month once it lapses. Proven by REG-ROLL-MANUAL-ANNUAL and a local end-to-end run (2026-09-25 billing QA), and present on a live production tenant (read-only report).
