## Reported evidence

After #3273 the API returns a coded 503 ORDER_SAVED_CREDITS_PENDING with orderId when an order saved but its credits did not apply, and replays carry a creditsPending hint. The mobile queue retries any 5xx and ignores the hint, so the user is never told to apply the credits on the saved order. Same as master today (not a regression).
