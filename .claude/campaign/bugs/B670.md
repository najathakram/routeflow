## Reported evidence

The SAVE path re-derives unitsPerBox from the live product record instead of the line's own stored snapshot, so a product repacked (unitsPerBox changed) after the sale re-prices an EXISTING line on the next save. Same class as the Senior Architect's ruling: a rewrite of an existing line must use its own snapshot; a null snapshot goes through legacyLinePieces and is refused on unknown. Found by S-order. Owner: U-units, to be folded into the buildLine conversion (W3).
