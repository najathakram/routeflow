## Root cause

Reported by the Order UI redesign session (PC) from #1288's pre-merge review; its new second-pass overflow probe caught it, and it's carved out with a named ignoreContainer. Verified present on origin/master 95c54ba3: the operator dashboard's order-pipeline strip is a 5-column grid (grid-cols-5, :802) of status-count links (Pending, Confirmed, Out for Delivery, Delivered, Cancelled → /orders?status=…) inside an overflow-hidden rounded card. At 390px, the last label 'Cancelled' (one word; the text-[11.5px] span) has scrollWidth 54 > clientWidth 31 and renders hard-clipped as 'Cancelle', with no ellipsis, wrap or scroll. Multi-word labels ('Out for Delivery') wrap instead. Cosmetic: the link and count stay usable, but it's visible clipping on the first screen every operator sees, and phones now get this web (#1320). Fix: allow the label to shrink (min-w-0 + truncate with an ellipsis, a smaller label at <sm, or a 3+2 / scrollable layout below sm), with a Playwright 390 pin. Screenshot available from the Order UI session. Owner: unassigned; likely the Order UI lane after #1288, with B823.
