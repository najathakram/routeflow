## Reported evidence

Create tenant admin succeeds (201, tempPassword and emailSent returned) but the Temporary password box and its note never render: handleCreateAdmin sets createResult, then calls onRefreshTenant() = fetchTenant, which runs setLoading(true); the page then returns 'Loading tenant…' and unmounts TenantAdminSection, discarding createResult. When the welcome email is not delivered the one-time password is lost; only a separate reset recovers access. Pre-existing on master; observed with a real API and web at #3794 1c26cfc8c (#3686 comment 6456126099), both emailSent=false and true. Acceptance: the temp password and the PR #3794 D12 note (adminCreatedNote(emailSent), both states) are visible after create; the fix PR carries the D12 capture at 1440/768/390.
