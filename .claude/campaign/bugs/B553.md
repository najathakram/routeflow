## Reported evidence

Independent Opus review of merged PR #913 (bebe66af): EntitlementAuthority's cache invalidation is an in-process Map.delete, not distributed -- a concurrent requires-check on ANOTHER replica can read a stale pre-grant/pre-revoke snapshot for up to the cache TTL. Worst case is a spurious 400 with an ack escape hatch already available (per #915), not a security hole. Recorded so it isn't rediscovered.
