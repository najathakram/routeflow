## Reported evidence

From the #2975 review (#2554), via the lead. CustomerFormModal's banner renders apiError.message, which for an axios error is the raw 'Request failed with status code 400' text, and since #2975 suppresses that form's toast the server's detail (e.g. an overlong or formula-led name refusal) is lost. Pre-existing. Fix: readable copy mapped from the server code/validation, never axios text; pin an overlong-name 400 case. Web, medium, UX. Owner lane: Lane B after #2975 lands.
