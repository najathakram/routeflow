## Reported evidence

_Imported verbatim from the bug register — this is the ORIGINAL report, not analysis._

**Meant to do.** Wipe-and-recreate happens only when the caller explicitly asks for it.

**Actually does.** allNewItems inferred replaceAll=true from the payload SHAPE (every item lacking an id) — exactly the shape mobile's per-scan add sends — so an add could delete every other line in the order.

**The gap.** A destructive mode was keyed off an accidental property of the payload instead of an explicit flag.
