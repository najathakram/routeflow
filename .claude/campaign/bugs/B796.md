## Root cause

Fleet lead relay, 2026-09-23 (Opus notes on #1298). Verified on origin/master 5ae97db7 (2026-09-23). SIX throws have a code and no message: CHANGE_WINDOW_CLOSED (reason ORDER_STATUS / RUN_NOT_ACTIVE) at :5066, :5069, :5197, :5200 and STOP_ALREADY_COMPLETED at :5076, :5206. CORRECTION to the relay: CONCURRENT_UPDATE is NOT message-less. Both its throws carry a message (orders.service.ts:5270-5275 'Another update changed this order line. Try again.' and db-locks.ts:407-412 lockRowsNoWait 'Another update to this record is in progress. Try again in a moment.'). With no message, e?.response?.data?.message is undefined and the client falls to e.message = axios's generic text, which B790 stores as the decline's resolutionReason and which is pushed to the driver. Fix: add a human message to each of the six throws (server, one place) and/or map code+reason to readable text on the client; pin it with a spec that every at-stop ConflictException carries a message. Owner: R-ui, after B784/B792/B788.
