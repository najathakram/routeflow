## Reported evidence

The buyer portal's <aside> is a fixed w-64 flex-shrink-0 rail with no lg:/mobile breakpoint classes, no off-canvas drawer, and no collapse toggle — on a phone it permanently occupies screen width instead of hiding behind a menu button, and there is no way to narrow it on desktop either. The tenant dashboard shell ((dashboard)/layout.tsx) already has the full pattern (collapse toggle, lg:w-16/lg:w-60 rail, mobile drawer, hamburger, localStorage-persisted state) — the buyer portal never got it.
