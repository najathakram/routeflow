## Reported evidence

priceMatchedChunk prices each returned slice independently, so a line returned in several slices can drift by up to half a cent per slice against pricing the whole quantity once. SA-576 allows the drift for now. Follow-up: telescope the chunk over the prior returns of the line (price the cumulative quantity, subtract what earlier returns already credited), the same shape as the invoice telescope, so slices sum exactly to the whole. Money-adjacent; test tenants only. Source: SA-576a, board #2554 comment 5897475530.
