# B360 · Nine routes accept @Body() dto: any, bypassing the global ValidationPipe (F4-003 remainder)

**Location** `API · validation (customers/estimates/inventory/returns controllers)` · **Severity** low · **Batch** F48 · **State** queued

## Summary

_Not yet analysed._

## What this feature is for

_Not yet analysed._

## Root cause

Handlers typed @Body() dto: any give the pipe no metatype, so whitelist and forbidNonWhitelisted never run.

## User impact

Unvalidated shapes reach services; POST /returns is reachable by CUSTOMER and DRIVER; the OPERATOR-only routes still bypass the mass-assignment guard.

## Fix approach and UX

One class-validator DTO per route (shared where shapes match) with array and string caps; only behavior change is 400 on malformed input.

## Test plan

T1: each route rejects an unknown property with 400; returns DTO enforces integer qty ≥ 1 and photoUrls max length; existing returns specs green.

## Reported evidence

With no metatype the pipe cannot whitelist or reject unknown properties; POST /returns is reachable by CUSTOMER and DRIVER. Expected: a class-validator DTO per route with array/string caps.
