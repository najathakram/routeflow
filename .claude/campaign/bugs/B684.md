## Reported evidence

B606's fix (feat/u-picker-5b-r, #1147) guards CreateOrderModal's remembered-price display so a line priced by a unit (li.unitLabel set) never shows a pack-denominated priceHistoryEntry next to its price input -- showing a per-box remembered price beside a per-piece input is actively misleading. Master has since added a second, independent consumer of the same priceHistoryEntry data in the scan screen's PriceEditor (apps/web/app/(dashboard)/orders/_components/scan/PriceEditor.tsx), which has no equivalent unitLabel guard. Once the unit picker (#1147) and the scan-screen price editor coexist on master -- true for this release -- a unit-priced line reached through the scanner can display a pack-denominated remembered price. Surfaced by U-units while working #1147; explicitly out of scope for that PR per the fleet lead. Fast-follow, not release-blocking.
