## Reported evidence

Order cancellation decides whether to credit stock back (cancelReturnsStock) from an order snapshot read before the cancel's own row lock is taken, and invoice write-off reads the invoice's status via an unlocked findOneOrThrow before writing WRITTEN_OFF unconditionally — both can act on a value a concurrent write has since changed.
