## Root cause

Fleet lead relay 2026-09-24 (Opus finding, same class as B679/SA-144e/f). manual-invoice-lines.ts:142 derives computeCategoryTax's unitBasisQty through the OLD inline basis instead of regulatedUnitBasis. Covers manual invoices, estimates and recurring invoices, all via invoicesService.create. Unit lines do NOT reach this path today (Opus verified), so no live exposure yet -- POST-R1. Fix: route through regulatedUnitBasis with a pack-label pin, same shape as #1356. Related: B679, SA-144e, SA-144f.
