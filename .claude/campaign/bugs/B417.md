## Reported evidence

Hit live on #746: after rebasing fix/F39-payments onto master, @{u} (origin/fix/F39-payments) was still pinned to the pre-rebase tip because that exact push had not yet landed. git diff --name-only "$upstream"...HEAD therefore included every commit the rebase replayed in, so SKIP_VERIFY=1 with no reason was refused even though the branch's actual new content (diff vs origin/master) was 100% docs. Fix: diff against git merge-base origin/master HEAD instead of/in addition to @{u} when they disagree -- the merge-base is unaffected by whether this branch's own remote-tracking ref has caught up yet.
