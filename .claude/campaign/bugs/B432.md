## Reported evidence

Verified against master d69f3094: emit()'s opts type declares amountDelta?: number | null (optional) and the write is amountDelta: opts?.amountDelta ?? null -- a call site that forgets to pass amountDelta silently books a billing event with zero money impact instead of failing to compile or throwing. Every MRR/reconciliation figure (mrr.service.ts's ledgerMrr/momDelta) sums this field directly, so a silently-null delta at any call site is invisible in every downstream money report with no signal it happened. Fix: make amountDelta required at the type level (drop the ? and the ?? null fallback) so a new call site is forced to explicitly pass 0 or a real value, never silently default.
