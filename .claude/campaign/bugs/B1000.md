## Reported evidence

From the lead's six-area UI audit (read from code on master 01b7eaa5; file:line in the audit notes). When a line has no stored subtotal the detail pages recompute qty x unitPrice, which over-charges a boxed line by unitsPerBox. Fix: use computeLineSubtotal from @routeflow/pricing, never re-derive.
