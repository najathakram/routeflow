## Root cause

Fleet lead relay 2026-09-23 (Order UI hit it twice). Verified on origin/master b6e6bc7f: apps/web/tsconfig.json:25 includes .next/types/**/*.ts, so @routeflow/web#check-types type-checks whatever generated types a previous next dev left behind. A stale file with a type error goes red, and tsc --noEmit is clean once .next/types is removed. Fix (pick one): a check-types tsconfig that drops .next/types from include, OR have check-types remove .next/types first. Pin: a stale generated .next/types file with a type error does not fail check-types. Owner: Order UI, after #1288.
