## Root cause

Hunt A3 (fleet lead relay). Verified on origin/master 2ed80789 (2026-09-23). :172 @Patch(':id') update(@Param('id') id, @Body() dto: Partial<CreateInvoiceDto>) — a TS utility type reflects as Object at runtime, so class-validator's ValidationPipe skips it entirely. shippingFee sent as the string '25' goes through roundMoney as 0 and desyncs the order; a negative discount is reachable from the web UI. Fix: class UpdateInvoiceDto extends PartialType(CreateInvoiceDto) (@nestjs/mapped-types) and bind that at :172. Money input validation.
