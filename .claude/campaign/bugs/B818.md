## Root cause

Verified at #1318's head 59623d67 (2026-09-23); from #1318's Opus review (PASS WITH NOTES; old code). findJunctions shells to PowerShell with -LiteralPath '${dir}' (a ' in the path breaks it) and returns [] whenever trySh fails, so a scan error looks like 'no junctions'. safeRemoveTree then ignores each trySh('cmd', ['/c', 'rmdir', junction]) failure and proceeds to the recursive delete without re-scanning. Fix: FAIL CLOSED: a scan error or an unlink failure aborts the removal; re-scan after unlinking and refuse if any link remains; escape the path. Owner: MacBook landing, stacked with B815/B816 after #1318 (its new containment guard may already cover parts; it verifies).
