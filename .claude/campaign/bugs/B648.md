## Reported evidence

RUN_LINE_ITEMS_SELECT omits unitLabel, so the driver run read carries no unit and the driver's client cannot tell a Case line from a pack line; this is the root cause of the driver short-pick problem in B643 (the stepper counts pieces). HOW KNOWN: sweeper x2 (two independent read-only sweepers agree); NOT verified by R-ui. ROOT CAUSE (shared with B641/B643/B644/B645/B646): computeLineSubtotal and normalizeBoxesPieces silently fall back to per-piece math when a caller omits the split or the factor, and no client type (web, mobile, @routeflow/types) carries unitLabel, so no client can be unit-aware; the fence (assertNoUnitAwareLines etc.) covers rewrite paths only, not client-typed quantities or documents.
