## Reported evidence

The local fast-path scan match used a bare .find() with no isActive check and no disambiguation, so a code shared between an active and an archived product (allowed by the per-column unique constraints) silently resolved by page order, and a genuine cross-field collision (one product's sku equal to another's barcode) was never surfaced to the operator.
