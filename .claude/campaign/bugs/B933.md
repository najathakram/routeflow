## Reported evidence

Keys shaped like the live or test Stripe prefixes never match, because the underscore after live or test breaks the character class, so the Plane mirror and any consumer of this denylist let real key-shaped strings through. Repro: new RegExp("(sk|pk)_[A-Za-z0-9]{12,}").test("sk_live_" + "a".repeat(24)) returns false. Fix: (sk|pk|rk)_(?:live_|test_)?[A-Za-z0-9]{12,} plus a whsec_[A-Za-z0-9]{16,} entry, with a spec case for each. Security and tooling. The control-system build adds its own supplemental patterns meanwhile and does not edit the shared file. Filed via the control-system lane.
