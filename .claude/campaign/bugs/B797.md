## Root cause

Fleet lead relay (Opus notes on #1299/B784), 2026-09-23. Verified on origin/master 5ae97db7 (2026-09-23). The server's assertInvoiceRewriteAllowed (unit-aware-guard.ts:143-179) checks the invoice's own unitLabel lines AND the linked order's non-CANCELLED lineItems with a unitLabel, and fails closed on an unreadable parent. The web edit page gates only on hasUnitLine(invoice.items) (edit/page.tsx:594), and #1299's mobile guard (invoice-line-unit.ts) likewise reads only the invoice's own items. Narrow case: a delivered or batched order carries a unit line, and the invoice lines were built by a path that drops unitLabel. The client lets the user into the editor, and Save gets the 409. No data risk (the server refuses). Fix: findOne exposes a hasUnitLines flag (or the server check's result), and both clients gate on it. Owner: R-ui, at the end of its queue.
