## Reported evidence

_Imported verbatim from the bug register — this is the ORIGINAL report, not analysis._

**Meant to do.** A cash variance, and the reason the driver was forced to type at run close, are reviewable by the office so a real shortage or overage can be investigated.

**Actually does.** closeRun appends the note to RouteRun.notes and then flips the run to COMPLETED in the very next call. The only UI that ever renders run.notes is the Edit Run modal, whose trigger is hidden for COMPLETED and CANCELLED runs.

**The gap.** The note becomes unreachable through every UI path the moment the run it describes closes — no read-only run view, operator screen or driver history renders it.

**Evidence.** Evidence · apps/mobile/app/(driver)/route/settlement.tsx:81-119 (note built and PATCHed at :107-111, then COMPLETED at :112 — always in that order), :83-90 (counted required, reason required on variance); the server does persist it (apps/api/src/routes/routes.controller.ts:265-274 and routes.service.ts:1278-1303); sole reader apps/web/app/(dashboard)/routes/_components/EditRunModal.tsx:13, :34, :110-113, opened only from routes/page.tsx:353 and gated at :492-500 on the run not being COMPLETED or CANCELLED; the run detail page never reads run.notes; grep for .notes across the web routes tree and the mobile operator tree returns only invoice, payment and stop notes.

**Suggested fix (register).** Render run.notes read-only on the run detail page for every status, or write the settlement result to a dedicated, surfaced field instead of appending to the free-text driver-notes column.

> ⚠️ Treat this as a hypothesis, not a plan. On F11 the adversarial pass refuted the
> suggested fix for every one of the four bugs while confirming every diagnosis.

**Verifier's note.** Lowered from High: nothing in the database is written wrongly and no money moves — the captured artifact is simply write-only. The note does persist server-side, so the premise holds. Supporting detail: the routes list comments that it shows active runs only, which makes the completed run's Edit path even less reachable.
