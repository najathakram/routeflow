## Reported evidence

SA-batch-1345 Q4(b): the claim is a status CAS and writes { shippedAt: order.shippedAt ?? new Date() } from its pre-read. On a legacy unstamped PARTIALLY_DELIVERED order the only racer is the fill-only backfill, so the order and the invoice mirror can differ by seconds on legacy rows. No money, no status change. Make the claim's stamp fill-only (same class as SA-1142 R2). XS; rides any later PR that touches order-status-claim.ts.
