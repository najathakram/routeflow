## Reported evidence

getTenantFromAddress() uses the raw smtpUser credential as the From address for tenant own-SMTP fallback: it is not CR/LF-sanitized and may not be an email at all (e.g. SendGrid 'apikey', an SES access key id). Should only be used if it is a valid address; otherwise the send should return delivered:false with a message like 'set a From email in Settings -> Email'.
