## Root cause

Fleet lead relay 2026-09-24 (vendor-bills lane). The server now refuses Σ allocations > payment total with 400 ALLOCATIONS_EXCEED_PAYMENT (#1296/B769, SA-112c), but the /finance/payments form lets the user build an over-allocation and only learns at submit. Fix: live remaining-to-allocate plus a disabled submit when Σ(rounded allocations) > total, using the same rounding (roundMoney per allocation, then sum) as standaloneAllocationTotals. Pin: an over-allocated form can't submit and shows the excess. Owner: vendor-bills lane.
