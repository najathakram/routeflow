## Reported evidence

SA-173 (board issue #2052): on the LIVE return path a legacy-shaped SALE row (qty equals unitBasisQty, box-unaware) on a product whose box size was removed after the sale is indistinguishable from a genuinely piece-axis row of a never-boxed product, so classifySaleAxis reads it non-boxed-now and the reversal books the box count as pieces. Fail-open on the regulated ledger, LIVE-NOW. Evidence that separates the two shapes: a linked source split, the SA-161 SALE-ledger ratio (unitBasisQty / qty integer > 1 for B661-written rows) or product pack-change history. The fix is in the resolver, own tier-1 read. The resolution walk (#1324, SA-173) already uses the operator-attested pack; the live path does not.
