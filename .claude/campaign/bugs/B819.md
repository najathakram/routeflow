# B819 · janitor isDirty treats a failed git status as clean, and --porcelain ignores gitignored .env and local-assets, which are lost on removal

## Root cause

Verified at #1318's head 59623d67 (2026-09-23); from #1318's Opus review (PASS WITH NOTES; old code). isDirty = !!(out && out.length > 0) where out = trySh('git', ['status', '--porcelain']), so a failing git status (out null) reads CLEAN. --porcelain also omits gitignored files, so a worktree's local .env and local-assets/ proofs count as clean and are deleted with the worktree. Fix: a git status failure → dirty (fail closed); also treat the presence of gitignored-but-valuable paths (.env*, local-assets/) as blocking, or list them via --ignored and refuse.
