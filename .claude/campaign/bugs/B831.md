## Root cause

From the janitor review (#1318), fleet lead relay 2026-09-23. Verified on origin/master 9e7e1721: scripts/repair-f03.mjs appends every applied repair to local-assets/repair-f03-<timestamp>.jsonl (:17 header, :333 path join), relative to the cwd's repo, and apps/api/src/scripts/repair-f03.spec.ts drives it, so every test run in every worktree drops a new jsonl. There are 156 such files under .claude/worktrees/*/local-assets/ on the Mac mini alone. local-assets/ is exactly what the janitor (after #1318) now treats as precious or blocking, so the clutter turns into false 'precious' hits and disk growth. Fix: under Jest (process.env.JEST_WORKER_ID), or through an injected log-dir option, write the log to os.tmpdir() or a caller-supplied dir, NEVER the repo. Add a spec asserting no file lands under the repo after a test run. Optionally, a one-time cleanup note. Owner: MacBook landing, after its janitor PR.
