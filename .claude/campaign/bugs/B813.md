## Root cause

SA-124d follow-up (fleet lead, 2026-09-23). B753 ships as built. SA-124b's Case-line pin is UNREACHABLE today because the units_v1 at-stop guard refuses the add with UNIT_AWARE_LINE when the product has a unit-sold line, so a driver's at-door PACK add can't reach that product's pack line either. Precondition for relaxing the guard: the change-request payload must carry unitLabel (null = the pack) so the server can route the add to the (productId, pack, unit)-matching line per B753/SA-124b. Pair it with adding that payload field (server DTO, and web and mobile clients). No owner yet.
