## Reported evidence

From the #3046 Opus review (#2554), via the lead; blocks B986 for these 4 surfaces. Four refusal families have no error code or structured fields, so the web cannot give fixed, actionable copy: (a) statement-apply refusals (draft bill X, the same bill twice, amount over the line or balance) need codes with the bill number and amounts as fields; (b) the supplier-payment per-bill allocation over balance needs a code with the bill and the remaining amount as fields; (c) the import 403 add-on gate must say WHICH add-on (MSRP, tobacco_dealer or forecasting) and be distinct from a role 403; (d) product-export date-range validation needs a code. API plus web, medium.
