Could not fully reproduce/refute against master with a complete jest run (all 4 workspaces) given this session's disk pressure -- that would be the real test. Open question: is this a genuine repo-wide registry/test-title mismatch, or an artifact specific to PR #871's branch (e.g. a jest run that didn't complete cleanly there, or a config/version skew)?
