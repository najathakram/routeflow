## Reported evidence

One instance already surfaced and was fixed: #792 removed a stray non-default export from (platform-admin)/layout.tsx that tripped Next's typed-routes check in dev but was silently masked in the production build by this flag (a static guard, app/layout-exports.test.ts, now catches that SPECIFIC class of error). The flag itself is untouched, so any OTHER type error introduced elsewhere in apps/web still ships to prod unnoticed until someone happens to run next dev locally and hits it.
