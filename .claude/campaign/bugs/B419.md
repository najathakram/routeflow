## Reported evidence

Hit repeatedly this session: bugs.mjs's own tags-array serialization (no space after comma) gets flipped to spaced by lint-staged's prettier --write on ANY commit touching the same directory, even when that file was untouched by the actual change -- observed on B388.md/B389.md across multiple unrelated commits. Separately, master itself carries at least two files (validate-code-map.stamp.self-test.mjs, code-map/api/root-tooling-campaign-infrastructure.md, both from #747/B420) that are not prettier-clean per a fresh checkout's lint-staged pass -- confirmed not a config drift (that PR was pushed with the verify skip), but it means ANY later commit that happens to touch those paths will show spurious reformatting churn. Fix: add .claude/campaign/** and .claude/lessons/** to .prettierignore (registry data owns its own exact serialization, same precedent as the already-prettier-ignored vendored skill scripts); separately, engine/builder commits should format only the paths they actually intend to change, not rely on a repo-wide format pass.
