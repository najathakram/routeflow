## Reported evidence

Prisma does not wrap these migrations in a transaction, so a migration that uses SET LOCAL outside an explicit BEGIN/COMMIT runs it as a silent no-op (the setting never applies to the statements after it). npm run lint:migrations passes such a migration. The guard should fail a migration that contains SET LOCAL with no enclosing BEGIN/COMMIT. Source: SA-582, board #2554. Tooling.
