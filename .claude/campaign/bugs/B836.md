## Root cause

Order UI report via the fleet lead, 2026-09-24. spec 52 gates on test.skip(!HAS_SUPER_ADMIN_CREDS), which is true only when PLAYWRIGHT_SA_USERNAME/PASSWORD are non-empty. It never consults e2e/setup/.auth/super-admin.json, so a valid saved session can't re-run the spec without the credentials in env, unlike the operator/customer/buyer projects. Fix: skip only when BOTH the env credentials are absent AND no unexpired storageState file exists. Pin: with the env unset and a valid storageState present, the spec is not skipped. Never commit the storageState (gitignored .auth).
