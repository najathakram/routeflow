## Reported evidence

safeRemoveTree runs rmdir /s /q on a plain FILE (for example a stray bugs-selftest.log), which fails on win32 and aborts janitor:apply before the Docker and npm-cache reclaim steps. Fix: stat the target and use unlink (or fs.rm) for a file, rmdir only for a directory, and keep the safety checks. Tooling. Found during the PC cleanup. Filed via the lead.
