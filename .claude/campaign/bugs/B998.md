## Reported evidence

From Mac Lead (lead-ruled). A formula-led VARIANT name in a product-family create or update is reported by the server's TEXT_CELL_FORMULA_LEAD refusal under field productName, so the web (#2919 CreateFamilyModal) shows it under Family name instead of the offending variant row. The server must name the row (for example details.variantIndex or the field path) before the web can place it. Goes with B991 / B987-E (structured refusal fields). Lane: U-units. API and web, low.
