# B279 · Marketing header Sign-in dropdown: focus ring painted per line box (icon / label / arrow) and the arrow wrapped -- the Radix menuitem anchor was display:inline; both items rested in low-contrast #6b81a0

**Location** `Marketing header . Sign-in dropdown (route /, components/site-header.tsx)` · **Severity** medium · **State** uncampaigned

## Summary

_Not yet analysed._

## What this feature is for

_Not yet analysed._

## Root cause

The Radix DropdownMenu.Item asChild anchor (role="menuitem") had no display in its structural rule, so it rendered inline; the ambient :focus-visible ring painted once per line box (icon, label, arrow), fragmenting into up to 3 rectangles, and the trailing ArrowUpRight glyph wrapped onto its own line. Resting colour was a low-contrast #6b81a0 shared by both Distributor/Retailer items.

## User impact

_Not yet analysed._

## Fix approach and UX

marketing.css only, no markup change (PR #673): .rf-marketing .signin-menu [role="menuitem"] gets display: flex; align-items: center; width: 100%; white-space: nowrap (one ~46px row instead of up to 3 line boxes); resting colour unified to #202124; :hover/:focus swapped to :focus-visible with its own outline + outline-offset on the anchor, and a new > * { outline: none } rule neutralises the icon/label/arrow children so the ring can never re-fragment.

## Test plan

3 new assertions in marketing-port.static.test.ts (CSS-rule parser, R-MKT signin-menu): structural rule has display:flex + white-space:nowrap; the anchor's own :focus-visible rule has outline + outline-offset; no inner-child rule paints a non-none outline. Suite 59/59 green. Playwright proof on a dev build at 1280px: focused item is one flex row, label/arrow top delta 1.7px (was up to 3 line boxes). Dropdown is hidden <=800px by design (hamburger sheet takes over) -- untested at that breakpoint by this pin.

## Reported evidence

Owner-reported 2026-09-08, keyboard focus at 1280px: each DropdownMenu.Item asChild anchor (role=menuitem, icon+label+ArrowUpRight glyph) had no display in its structural rule so it stayed inline; :focus-visible painted one outline rectangle per line box (icon, label, arrow each wrapped separately) instead of one ring around the row, and both items rested in a low-contrast blue-grey #6b81a0. Evidence: local-assets/handoff/2026-09-08/signin-menu-before-1280.png (machine-local, not committed; cited in PR #673's body).
