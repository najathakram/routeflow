## Root cause

Contract hardening (fleet lead, from SA-091b, 2026-09-23); verified on origin/master 2ed80789: `throw new ConflictException("Return changed state during credit issue — retry")` (:421-422) carries no machine code. #1270's offline-drain settle logic must NOT settle the nonce on this retry-409, and today can only recognise it by the message suffix; #1270's next push pins that literal on both sides as the interim guard. Fix: give it a code (e.g. RETURN_STATE_RACE_RETRY) in the exception body and match on the code on mobile; keep the literal pin until both sides move. Low/medium — a reworded message would silently break the client's settle rule.
