Asked for by SA-106 (2026-09-23, from the #1292/B663 read); fleet lead rating HIGH, money; verified on origin/master 2ed80789. completeWithPayment records delivery mutations only when dto.deliveries is non-empty (~:2558), but step 3 then runs tx.order.updateMany({ where: { id: { in: stop.orders.map(o => o.id) }, status: { notIn: NON_ROUTABLE_ORDER_STATUSES } }, data: { status: DELIVERED } }) (~:2589-2598) for EVERY order on the stop, with or without entries. The reconcile's create-if-missing branch (which SA-106 keeps) then drafts the FULL remainder for an order that has no delivery evidence at all.
