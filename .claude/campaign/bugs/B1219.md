## Reported evidence

When a scanned code has no exact barcode/SKU/unit/barcode-table match but the fuzzy search returns exactly one product, the shared ladder adds that product without asking, so an unknown code can add an unrelated product. Affects every caller of the shared ladder (Create Order, counter sale). Found in review of #3279; fix belongs in the shared ladder, not B1210.
