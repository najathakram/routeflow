## Reported evidence

The order step queries DELIVERED and REFUSED orders (:128-131) but the empty text still says "No delivered orders for this customer." (:144), and each row shows o.deliveredAt ? date : "delivered" (:158-159). A refused order is written with { status: REFUSED, deliveredAt: null } (apps/api/src/routes/stop-outcome.ts:69), so every refused order in this list is labelled "delivered", not just some. Fix: "No delivered or refused orders for this customer." and show "Refused" (from the status) when deliveredAt is null. Source: bug hunt 2026-11-06, verify-ui C-5 (confirmed, read at 7be372afed).
