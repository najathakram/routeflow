## Root cause

Fleet lead relay, 2026-09-23 (MEDIUM-HIGH, money; filed HIGH). Verified on origin/master 78518274. recordPayment: alreadyPaid = inv.payments.reduce((sum, p) => sum + Number(p.amount), 0) (unrounded float sum), totalOwed = Number(inv.total), remaining = totalOwed - alreadyPaid. Then 'if (remaining <= 0)' refuses, 'if (dto.amount > remaining + 0.001)' refuses as an overpayment, and totalPaid = alreadyPaid + dto.amount decides PAID with 'totalPaid >= totalOwed', else PARTIAL. Example: 0.70 already paid plus 0.10 gives 0.7999999999999999, so a 0.80 invoice/bill stays PARTIAL. The remaining ~1.1e-16 is still > 0, so it's never 'fully paid', and every further payment above 0.001 is refused as exceeding the balance: the document is stuck PARTIAL. payBillFully (~:742-758) already does newPaid = roundMoney(alreadyPaid + remaining). Fix: roundMoney alreadyPaid, remaining and totalPaid (or compare within 0.005), with red-first pins: 0.70 + 0.10 on a 0.80 total → PAID; a third payment refused as 'already paid' rather than an overpayment. Owner: the unit-picker lane (it knows this file from B781/SA-121), after B780.
