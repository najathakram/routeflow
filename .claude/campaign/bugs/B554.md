Independent Opus review of merged PR #913 (bebe66af): the tenant self-serve SubscriptionMutationService.enableAddon path (any OPERATOR) still has no requires check at all, and its invalidate call only clears entitlements, never featureResolver -- same stale-cache class B524 fixed elsewhere. Needs its own id so it isn't lost.
