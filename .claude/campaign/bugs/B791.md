## Root cause

Fleet lead filing request (2026-09-23); verified on origin/master 2ed80789: inside describe('refresh — in-place rotation (B155)') (:602), `const stored = { … expiresAt: new Date(Date.now() + 60_000), … }` (:604-608) is at DESCRIBE-BODY scope, so Date.now() is evaluated at Jest COLLECTION, not when the tests run. When the api suite is slow (> 60 s between collection and these tests — 8 GB hosts, CI under load, the throttled mini), 4 tests hit auth.service.ts:271 `throw new UnauthorizedException('Refresh token revoked or expired')` and fail — a false red that blocks verifies/pushes on slow hosts. Fix: build `stored` in beforeEach (fresh Date.now() per test) or use a far-future fixed expiresAt; also sweep this spec for the same pattern (:190 lockedUntil, :439/:466 expiresAt use Date.now() + 60_000 — check whether they are at describe scope too). Owner: the MacBook lane ('Extract and fix vendor-bills poTotal drift'), as a tiny separate PR after its B768 push.
