## Reported evidence

credit-notes.service.ts:918-951 voidCreditNote never checks Return.creditNoteId. processRefund claims a return REFUNDED then mints the credit note ISSUED, so the CN is voidable immediately afterward; once voided, the return is stranded REFUNDED with no credit and no path back (cancel already refuses a REFUNDED return, :858-859). Fix: refuse void of a CN referenced by a REFUNDED return, or reset the return's state in the same transaction. Found by MacBook's A2 state-machine verifier, pre-existing on master, fast-follow.
