## Root cause

Customer statement and available-credit figures are never invalidated when a credit note changes

Symptom / evidence: With the statement open, issuing or voiding a credit note leaves outstanding, available credit and the ledger showing pre-credit-note numbers; refetchOnWindowFocus is off, so only a remount past 30s fixes it, and a remote void emits no event at all.

Files implicated: apps/web/lib/api/credit-notes.ts, apps/web/lib/api/customers.ts, apps/web/lib/hooks/useRealtimeUpdates.ts, apps/api/src/credit-notes/credit-notes.service.ts.
