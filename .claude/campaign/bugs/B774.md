## Root cause

Hunt B3 (Lane IR hunt, fleet lead relay). Verified on origin/master 2ed80789 (2026-09-23). :226-229 takes unitsPerBox from matchingSet.find(l => l.productId === item.productId) — the FIRST line for the product — and :302 orders invoices issueDate desc, so it is the NEWEST line's pack, not the line the operator is returning. QuoteInlineReturnItemDto carries only productId/qty/boxes/pieces — no line id on the wire. 1 box against a 4-pack line when the newest line is a 16-pack credits $80 instead of $20 (4x). A null factor with no box size: returnRequestPieces (inline-returns-pricing.ts:143-145) = boxes × 0 = 0 pieces → a $0 credit. Add-on gated (orders_inline_returns). SA-101 RULING: separate from #1190 PR B; INTERIM refuses (409) when candidate lines span more than one pack and never credits $0; DURABLE fix carries orderItemId on the wire.
