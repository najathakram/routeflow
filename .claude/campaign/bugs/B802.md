## Root cause

Fleet lead relay (finding A4-F3), 2026-09-23. Verified on origin/master b8863d56. needsPackResolution (line-pack-factors.ts:37-38) = !hasSplit(li) && (li.unitsPerBox > 1 || li.product?.unitsPerBox > 1). A units_v1 line sold by the Piece unit (factor 1) is stored {boxes: null, pieces: null, unitsPerBox: 1}, so it has no split and its own upb is 1, but the LIVE product.unitsPerBox > 1 makes it 'need' pack resolution. It then resolves as unknown and legacyLinePieces parks it, so a standard return of that line parks instead of crediting. PackLine carries no unitLabel, so the function can't tell a unit line from a legacy boxed one. Impact: units_v1 only (test tenants in prod). The fix is already built at 62fa84b2 by the MacBook landing: select unitLabel on the line, and skip pack resolution for a non-blank unitLabel (the unit line's factor is authoritative). Owner: RouteFlow MacBook landing.
