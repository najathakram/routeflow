## Fix approach and UX

Nginx runner stage ran as root (no USER directive); api and web already fixed. Now switched the runner base image to nginxinc/nginx-unprivileged:alpine, which redirects nginx's pid/cache/temp paths off /var/run and /var/cache onto world-writable /tmp and drops to its own non-root nginx user by default -- avoids hand-patching plain nginx:alpine's internal directory layout, which can't be verified without a Docker daemon (not available in this session's sandbox). Static files are explicitly chowned to nginx:nginx after COPY since default COPY ownership under USER root can't be assumed. Default listen port changed 80->8080 (a non-root process can't bind <1024); Railway already injects a real $PORT at runtime (same assumption apps/web's USER node fix already relies on) and railway.toml's healthcheck is path-only, so no config elsewhere references the old port. NOT verified with an actual docker build/run in this session (no Docker daemon here) -- needs a real build/deploy check before this is trusted.
