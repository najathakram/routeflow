## Reported evidence

A legacy boxed line (boxes non-null, unitsPerBox null — from pre-#1159 duplicates and historical estimate conversions) hydrates wrong on invoice edit in both clients. Mobile ((operator)/(tabs)/invoices/[id]/edit.tsx:123) has NO fallback: it withholds boxes/pieces and re-prices the line 12x on save. Web falls back to the LIVE product pack (it.unitsPerBox ?? it.product?.unitsPerBox), which the Senior Architect ruled out for existing lines. Fix for both: derive the pack exactly from the line's own split via packFromOwnSplit, never the live pack. Owner: S-order (mobile invoice edit), after B672. Found by R-ui.
