## Reported evidence

Meant to do: dead-model-guard flags a safety check reading a model nothing writes -- the B54 shape. Actually does: flags models that ARE written, whenever the write goes through an inline this.prisma.forTenant().model.create(...) chain, asserting with full confidence they are 'never written anywhere in apps/api.' Produced two false leads: userPreference and importQueueItem -- for the second, the writes are in the SAME FILE the scanner flags, at lines 127, 142, 218, 353, 400, 477 and 506, while it flags reads at 258, 421 and 525. Cause, one sentence: the write-pass regex at scan-signatures.mjs:1107, /\b[\w$)\]]+\.(\w+)\.(create|createMany|update|updateMany|upsert|delete|deleteMany)\s*\(/g, starts with \b, and there is no word boundary at the ) that ends forTenant() because the character before it is (, so the chain cannot anchor and is invisible to this pass. The read pass explicitly alternates (?:prisma|tx|forTenant\(\)) as its receiver and therefore sees the same models fine -- reads credited, writes not; that asymmetry is the whole defect. Why the self-test did not catch it: the signature's own clean fixture writes through an aliased client, db.fixtureLedger.create, with a comment saying that is the receiver shape the write pass actually credits -- the fixture encodes the limitation instead of testing it. Blast radius, measured: 67 models in apps/api are written via an inline forTenant() chain; 22 are written ONLY that way and are latent false leads the moment anything reads them, including regulatedFiling, tobaccoReport, trackedCategory and trackedSubcategory -- the compliance surface. Suggested fix: add forTenant\(\) to the write pass's receiver alternation as the read pass already has, or drop the leading \b; replace the clean fixture with the inline shape so the self-test proves the real case, with two of the 22 as regression fixtures. Verified by running the regex against the real files, not by reading it. This is the scanner relied on for pre-PR gating, and it has been quietly blind to the most common write shape in the codebase. Fast-follow, not release-blocking. Filed per the fleet lead's request, sourced from the MacBook lane.
