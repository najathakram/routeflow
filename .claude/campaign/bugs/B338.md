## Summary

Customer.zohoContactId is globally unique but looked up tenant-scoped, so cross-tenant collisions are silently counted as "skipped"

## What this feature is for

## Root cause

Customer.zohoContactId is globally unique but looked up tenant-scoped, so cross-tenant collisions are silently counted as "skipped"

Symptom / evidence: Importing a contact list whose Zoho ids exist in another (or a null-tenant) row reports "0 created, N skipped" with no error line; nothing was created in this workspace.

Files implicated: apps/api/prisma/schema/sales.prisma, apps/api/src/import/import.service.ts, apps/web/app/(dashboard)/settings/import/page.tsx.
