## Reported evidence

B896 made lint:migrations refuse a top-level SET LOCAL that sits outside an explicit BEGIN/COMMIT. It only checks placement, so a migration with no SET LOCAL at all passes even though SA-582 requires every new migration to open with the wrap (BEGIN; SET LOCAL lock_timeout; ...; COMMIT;). #2765's unwrapped migration passed lint for that reason. Fix: in diff mode, require the wrap on every NEW migration in the --base range (a file not in the applied-exempt table, matched by folder name and sha256), and fail with <file>: missing SA-582 BEGIN/lock_timeout wrap. Source: board #2554 comment 5897342138 (the #2765 review). Tooling; touches migration checks, plan-only for agents.
