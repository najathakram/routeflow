## Reported evidence

Latent, no caller today. Since #4225 (F05 PR A) the SYSTEM kind is meant to exist only inside prisma.forSystem(reason, fn), which the for-system.allow-list.spec lists call site by call site. But TenantContextService.run(tenantId, fn, tenantless, label) is public and takes any tenantless kind, so any code can call tenantCtx.run(null, fn, "SYSTEM") and the guard then never reports a tenantless write or read for it, with no allow-list row and no 12-character reason. Read at 266095419c: no non-spec source passes "SYSTEM" to run() (the literal is passed only inside forSystem), and several files call run(null, ...) already. Fix (PR-2 of F05, SA-1105): a spec that fails on any run( call naming SYSTEM outside forSystem, or a type that removes SYSTEM from run()'s accepted kinds and a private entry for forSystem; the pin belongs in the PR that starts converting system callers, before enforcement is switched on. Found in review of #4225 (lead's note).
