## Reported evidence

The end-of-import invoice status sweep compare-and-sets each row on {id, status} only; a status that changes away and back to the same value between the sweep's read and its update is invisible to the CAS, so a concurrent write in that window can be silently overwritten with no reported count. (GitHub #2471)
