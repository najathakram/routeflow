## Reported evidence

Web has OrderLineUnitPicker wired into the create modal, reads flag.units_v1, and calls the product-units endpoint. Mobile has no equivalent picker, no read of flag.units_v1, and no call to any product-units endpoint anywhere in the app. apps/mobile/lib/order-item-diff.ts:187-193 documents that a unit label rides along unchanged because that screen never sets or clears one -- mobile can DISPLAY a unit-sold line (created on web) but can never originate or change one itself. Parity gap on a feature the owner asked for directly. The mini is building it now. High severity.
