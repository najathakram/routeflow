## Reported evidence

The PR body Owner setup steps 3 and 5 and the dashboard empty state tell the owner to run ctl seed and ctl lane register. Neither exists: ctl lane register x exits 2 (unknown subcommand register) and ctl seed exits 2 with the usage text. Nothing creates the orphan ctl/state branch on a real origin (only fixture mode does). Repro: an empty bare repo as CONTROL_STATE_ORIGIN, then ctl next prints UNAVAILABLE clone failed: Remote branch ctl/state not found, and ctl start RF-1 --lane x exits 5 with the event parked in pending/; the server cannot clone it either. Blocks first use; no data risk. Fix: a small follow-up code PR adding ctl init and ctl lane register <id> --name --machine --kind, tests first, plus a README runbook.
