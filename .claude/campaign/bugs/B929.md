## Reported evidence

Nested writes (items: create or createMany) leave tenant-owned children with NULL tenantId; tenant-scoped child queries then miss them. Affected children (nullable tenantId): VendorBillItem, InvoiceItem, EstimateItem, OrderItem, OrderTemplateItem, RecurringInvoiceItem, ReturnItem, RouteStop, PurchaseOrderItem, BillPayment. Systemic parent of B928 (the vendor-bill instance). Fix: B1 the tenant extension stamps nested writes via a DMMF walker; B2 parent-scoped child deletes now, starting with vendor-bills update(items); the owner count-only NULL query first; backfill only by owner decision. Money and tenancy. Source: SA-620 (#2554 5920439272), U-po found the instance.
