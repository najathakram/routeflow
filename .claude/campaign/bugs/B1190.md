## Reported evidence

On a new compose project (empty volumes), local:seed needs scripts/lib, scripts/native-parity, apps/api/scripts/lib, prisma/seed-parity-buyer.ts and src/billing inside the api image, which lacks them, so they had to be docker-cp'd in by hand.
