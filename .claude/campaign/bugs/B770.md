## Root cause

From the Order UI lane's overflow probe (fleet lead relay 2026-09-23); verified on origin/master 2ed80789: the page's PageHeader `action` is `<div className="flex items-center gap-2">` (invoices/page.tsx:566) — no flex-wrap, no min-w-0. At 390px the rightmost button, 'New Invoice' (the page's PRIMARY action), overflows by ~67px. It is UNREACHABLE because the dashboard shell's main is `overflow-x-hidden` (layout.tsx:1382): no horizontal scroll exists. 768 and 1440 are fine. Same shape as B749 (customers/page.tsx:753). NOTE: the layout-level overflow-x-hidden turns EVERY overflowing row in the dashboard into an unreachable one — a class, see also B540/B750. Owner: the Order UI lane, fixing B749 + B770 together in one 'unwrapped toolbar row' PR, preferably at the shared PageHeader actions slot so every list page is covered, with 390px before/after captures.
