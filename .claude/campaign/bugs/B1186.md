## Reported evidence

With the pg driver adapter, Prisma leaves meta.target unset on P2002 and puts the index in meta.driverAdapterError.cause.constraint; every code path that detects a unique-key race by reading meta.target never matches, so the loser of a concurrent insert gets a raw P2002/500 instead of its retry/replay. Found by #3256 (BUG-A A4). SA-717.
