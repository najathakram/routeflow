# B891 · Web InlineReturnSection gives every line's Qty input the same id, so the labels point to line 1 and later lines are unlabelled

**Location** `apps/web/app/(dashboard)/returns/_components/InlineReturnSection.tsx (per-line Qty input id)` · **Severity** low · **Batch** F64 · **State** already-fixed

## Root cause

The root is the shared web Input, not InlineReturnSection: packages/ui/src/web/Input.tsx:15 sets `const inputId = id ?? label?.toLowerCase().replace(/\s+/g, "-")`, so every Input with the same label and no explicit id renders the same id (here "qty-(pieces)" on every line), and each <label htmlFor> points at the first. Fix at the root (lead): default the id to React.useId() when none is passed, which gives every instance a unique id app-wide; pin it with an RTL getByLabelText per line.

## Reported evidence

Every line's Qty input renders id="qty-(pieces)"; both <label htmlFor> point to line 1's input, and line 2+ inputs have no accessible label; clicking a later line's label focuses line 1. Pre-existing; found by F2 during the #2712 captures (#2554 5877344670). Fix: a per-line unique id (e.g. by line key) + an RTL pin getByLabelText per line.
