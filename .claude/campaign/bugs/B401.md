## Reported evidence

The admin plan change surfaced no prorated figure and applied changes instantly in BOTH directions, so it could strip a paying tenant's plan mid-cycle with no credit. Fixed: upgrades prorate and stay instant, downgrades schedule at period end like the tenant path, and the change is refused in either direction while a cancellation is armed. Note: the row's original premise (a Stripe-sync gap between admin and tenant paths) was partly wrong — both paths are Stripe-silent, so there was never an admin-vs-tenant Stripe difference; that half is not filed.
