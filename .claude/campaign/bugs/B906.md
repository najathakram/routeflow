## Reported evidence

Two log lines write a person's email address to the application log: line 344 logs `Google account linked for user <id> (<email>)` and line 730 logs `BuyerAccount created via Google: <profile.email>`. An email is personal data and does not belong in logs that are shipped and retained. Fix: log ids only (user id, buyer account id), never the email, and pin it with a Logger-spy spec that fails if either message contains the address. Also tracked in ticket #2775. Privacy. Source: board #2554 comment 5901178812.
