## Summary

## Root cause

Hunt A4 (fleet lead relay). Verified on origin/master 2ed80789 (2026-09-23). receivePO binds @Body() dto: any (controller :221), no DTO/class-validator. Service :1258 takes receivedQty = recv.receivedQty ?? recv.qtyReceived ?? 0 unvalidated; :1282 newQtyReceived = Number(item.qtyReceived) + actualQty string-concatenates when actualQty is a non-numeric string. Fix: a real ReceivePurchaseOrderDto with @IsNumber / @Min(0) per line.
