## Reported evidence

Prerequisite for B737. ProductUnitsController exposes create/read/update/delete for /products/:id/units with label, factorToBase and all five price fields (price + priceTier2-5) already in its DTOs -- the API-side capability is complete. Grepped web and mobile for any caller of this route or any 'product-units' screen: none exists. So even with flag.units_v1 on, nobody can set a unit level's explicit price (e.g. $1.29/unit on a 15-unit case priced $12.59) -- the only lever left is the case price, which derives a wrong per-unit figure by division. This is the missing screen that would let an operator actually enter the owner's reported case.
