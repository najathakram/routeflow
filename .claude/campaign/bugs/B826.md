# B826 · apps/web/Dockerfile doesn't declare ARG NEXT_PUBLIC_MOBILE_WEB_URL, so a Railway variable is never baked into the build and the code default is always used

## Root cause

Verified at #1320's head 927d514e (2026-09-23), fleet lead relay. The Dockerfile bakes NEXT_PUBLIC_API_URL, NEXT_PUBLIC_GOOGLE_MAPS_KEY and NEXT_PUBLIC_RELEASE_SHA via ARG/ENV (:49-63), but not NEXT_PUBLIC_MOBILE_WEB_URL, which #1320's lib/driver-app-link.ts reads (process.env.NEXT_PUBLIC_MOBILE_WEB_URL ?? 'https://routeflowmobile-production.up.railway.app'). A Railway service variable therefore never reaches the client bundle, and the default is always used. The default is correct today, so no live impact. Fix: add ARG NEXT_PUBLIC_MOBILE_WEB_URL + ENV like the others. Owner: the unit-picker lane, folded into phase 1a.
