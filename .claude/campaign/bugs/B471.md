## Reported evidence

The Lite locked route renders without the dashboard shell (no sidebar or header). DashboardLayout wraps AuthGuard->RouteGuard around DashboardShell, so the locked panel replaces the whole shell, and a LITE user can only leave via 'See plans' or the browser Back button. Fix: render the locked panel inside <main>. Spec 48 should assert the sidebar is present. Needs 1440/768/390 proof.
