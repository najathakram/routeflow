## Reported evidence

F12 recorded residual (fix-round-4-result.json recheck verdict 'not-fixed' for 'Round-3 residual [1] -- underway run with no caller clock appends unassigned stops with no window pass'): optimizeRoute's windowClock gate (route-optimization.service.ts, if(windowClock)) is byte-identical to round 3 -- when a run is IN_PROGRESS and the caller passes no clock, the post-solve window pass is skipped, so a stop the ORS branch reports unassigned is appended to the order with windowsChecked:false and never evaluated against the run's actual (stale) scheduled departure. Deliberately left untouched by #652 (round-4's edit was confined to the ORS unassigned type filter, which can only shrink the appended set, never widen this residual).
