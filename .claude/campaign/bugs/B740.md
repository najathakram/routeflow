## Reported evidence

Confirmed by trace during #1264's review: the identical operator action (picking a Case-level unit) produces a genuinely unit-aware server-side line on mobile (NewOrderScreen.tsx:1893-1897 puts unitLabel on the create payload when set; order-item-diff.ts:215-220 does the same on update) and a plain pack-priced line with only a cosmetic label on web (B737 -- the toggle changes how a quantity reads, never what is charged, no unitLabel sent at all). This repo's stated convention is 'mobile mirrors web' -- here mobile is ahead and web needs to catch up, the inverse of the usual direction. Not a defect in either individual PR; a cross-surface parity gap surfaced only by comparing them directly. Related: B737 (web toggle display-only), B738 (no client can set a unit price), B739 (a unit-aware line can't be edited once created).
