## Reported evidence

The AST scanner in unit-line-writers.ast.spec.ts only inspects methods inside class declarations. An order-item writer extracted from OrdersService to a top-level exported function (the order-lifecycle.ts verbatim-move pattern) silently falls outside the guard's coverage; found when deleteOrder's move made its INVENTORY row stale. Fix: the scanner follows exported functions in the sibling files it already knows, or an inventory-completeness check fails on a writer found outside any class. Owner: U-units lane, post-deadline; priority medium.
