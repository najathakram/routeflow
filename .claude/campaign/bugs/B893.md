## Reported evidence

The hook refuses a push only when the CHECKED-OUT branch is main/master; `git push origin feature:master` from any other branch passes the local guard. GitHub branch protection and rulesets are NOT available on this private repo (the API returns 403 'Upgrade to GitHub Pro or make this repository public'), so the local hook is the only trunk guard while private. Fix: reuse B892's pre-push stdin parse (RF_PUSH_REFS) and refuse if ANY remote ref is refs/heads/master or refs/heads/main; a fixture test pushing feature:master is refused.
