## Reported evidence

Verified via DNS-over-HTTPS (2026-09-18): www.routeflow.info resolves fine (CNAME to Railway), but the bare apex routeflow.info returns only an Authority/SOA record from Google Cloud DNS -- no A/AAAA record published at all. The zone exists and is authoritative; nothing is there. Every visitor who types the domain without www gets nothing -- customer-facing. An apex record cannot be a CNAME; this needs an A record (or Railway's documented apex-domain setup, e.g. ALIAS/ANAME if the DNS provider supports it) added to whatever manages the Google Cloud DNS zone. NOT a repo/code change -- a registrar/DNS console action. This has been surfacing as a recurring post-deploy-check warning that nobody owned, which is why it needs an id instead of staying invisible in a log.
