## What this feature is for

## Root cause

An offline-queued driver return is reported as "still to send", inviting a resend that can file the return twice

Symptom / evidence: Filing a return offline queues the POST but toasts "(1 order still to send)"; a retry can create a second PENDING return for the same goods whenever twice the undelivered qty still fits the ordered qty.

Files implicated: apps/mobile/app/(driver)/route/stop/[stopId]/return/index.tsx, apps/mobile/lib/returns-logic.ts, apps/mobile/lib/api-client.ts, apps/api/src/returns/returns.service.ts.
