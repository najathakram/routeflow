## Reported evidence

In the back-office Feature Console a stored mode (a row in the feature config) cannot be set back to Not configured: the preview's 'before' ignored the stored row, so the change read as no difference and Confirm was disabled. The card preview shared the read. Fixed with SA-1028 section 5 (FeaturePreviewService reads each key through FeatureConfigService.getState).
