# B806 · apps/api check-types never type-checks spec files (tsconfig.json excludes **/*.spec.ts), so a mistyped fixture reaches CI (#1286's taxNone = () => 0)

## Root cause

Fleet lead relay, 2026-09-23. Verified on origin/master: apps/api/tsconfig.json:26 has exclude ["**/*.spec.ts", "**/*.test.ts", "prisma.config.ts", "scripts/**", "prisma/**"], and apps/api check-types = 'tsc --noEmit' against that tsconfig, so no API spec is ever type-checked by npm run verify (only apps/api/tsconfig.plan-gate-specs.json covers a narrow set). #1286's stale taxNone = () => 0 fixture (a bare number where {amount, snapshot} is required) type-checked nowhere and failed only at runtime in CI's DB lane (5/229). Fix: a tsconfig.spec.json (extends tsconfig.json and includes the specs) plus a check-types:specs step in verify. Expect a backlog of existing spec type errors: either fix them in the same PR or start with a SHRINK-ONLY allow-list of files, pinned by a repo-truth spec. No owner yet.
