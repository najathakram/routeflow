## Reported evidence

F16b/B100 cause refutation + engine final pass, 2026-09-08: bugs.mjs:111 defines REPO_ROOT = join(dirname(fileURLToPath(import.meta.url)), "..", "..") specifically so path resolution is "independent of cwd" (its own comment, :107-110) - but rootDir() (:117) does not use it: process.env.BUGS_ROOT || ".claude/campaign", a bare relative literal that Node resolves against process.cwd() when it reaches readFileSync/writeFileSync/mkdirSync. CATALOGUE (:118), STATUS_DIR (:119) and BOARD (:123) are all derived from rootDir(), so every file/sync/index/move invocation without an explicit BUGS_ROOT reads and writes wherever the invoking shell happens to be cwd'd, not the repo (or worktree) the script lives in - exactly what wrote registry rows into the root checkout on 2026-09-08 (reverted). REGISTER (:122) and PIPELINE_DIR (:127) share the identical env-override-with-bare-relative-fallback shape. Fix: default rootDir()/REGISTER()/PIPELINE_DIR() off REPO_ROOT the same way :111 already does, or fail loudly when the resolved root's nearest .git does not match REPO_ROOT.
