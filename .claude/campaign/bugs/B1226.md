## Reported evidence

When an inline return is resolved as a recorded cash/card refund, accrual net sales drops by the refund INCLUDING tax while gross is pre-tax (total minus taxAmount), so net sales is understated by the refunded tax. The comment at ~:272-274 assumes Return.refundAmount is pre-tax, which holds for the standard refund path but not the inline one (refundAmount = the quoted total incl. tax). Same class as the credit-note term flagged by the code TODO 'B459' at ~:255-259. Reporting only (net sales, P&L revenue, sales facts); no invoice, payment or stock effect. Pin: an inline refund of 10.80 on a 10.00 + 8% line must reduce net sales by 10.00.
