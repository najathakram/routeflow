## Reported evidence

Independent Opus review of PR #926: in the Suspend direction, 'before' is read and the compensating-delta decision made from that snapshot, but the actual write isn't gated on that snapshot still being current -- no compare-and-swap. Two concurrent Suspend calls on the same tenant could each independently emit a compensating delta (e.g. -$499), double-counting the correction in the ledger. Narrow race window (requires two near-simultaneous Suspend calls on the same tenant) but real.
