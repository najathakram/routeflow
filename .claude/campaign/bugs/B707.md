## Reported evidence

Mobile edit-items.tsx:152-160 seeds unitsPerBox from the live product, never from li.unitsPerBox -- #1171 fixed only adjust.tsx, not this screen. Two failure modes: every mobile save of an order holding a unit line is refused with a 409 UNIT_AWARE_LINE (the line's own snapshot never reaches the request); and a repacked legacy split line is silently re-denominated at save (22.50 -> 21.25 in the observed case). Fifth instance of the live-pack-reinterpreting-a-stored-line class tonight (sibling of B657/B674, and of the pack-at-sale/notes-only-save/invoice-update() ids filed alongside this one). Fix: read lineUnitsPerBox(li) from at-door-line-units.ts, the same helper the fixed screen uses; carry unitLabel through. High, fast-follow.
