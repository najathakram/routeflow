## Reported evidence

Verified: local-env.mjs's --e2e mode hardcodes PLAYWRIGHT_TENANT_SLUG=e2e-routeflow, but apps/api/prisma/seed.ts (the local:seed target) only creates/seeds tenant slug 'test'. Every local e2e run against a freshly-seeded compose stack therefore has no data for e2e-routeflow, producing 7 F27-gate failures that all trace to missing data, not real regressions: CP-01 (its amount regex reads the empty-state text as an amount), CP-09/REG-B154 (empty products), ESC-01/ESC-02/BOXED-01 (no customer found), and REG-B130 (a strict-mode .or() locator, ambiguous when the page is in its empty state). Master's prod E2E (a real run against seeded prod-equivalent data) passed the identical specs -- confirms this is a local-lane data mismatch, not a product regression. Fix: seed e2e-routeflow locally (or point the local e2e lane at test instead), and separately harden CP-01's amount regex to not match empty-state text and fix REG-B130's ambiguous .or() locator so an empty-state page fails clearly instead of ambiguously.
