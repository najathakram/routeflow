## Reported evidence

When a checkout completion is refused (e.g. a customer mismatch, #3226), the session's add-on items can keep billing in Stripe with no row owning them; this is visible only in the STRIPE_CHECKOUT_REFUSED trail and error logs. Billing notifications go to the tenant's own admins, so there is no platform-admin alert. Add one.
