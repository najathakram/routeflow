## Reported evidence

create() commits the order, then the credit sync inside retryCreditTx can exhaust and return 503 LOCK_UNAVAILABLE 'Nothing was saved; please retry' although the order WAS saved. The web keeps the idempotency key and resubmits; the pre-check replay path never re-runs the credit sync, so appliedCreditNotes are silently missing. Found by the W17 bug hunt.
