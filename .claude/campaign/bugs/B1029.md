## Reported evidence

From the lead (owner ruling 2026-10-03: bill it properly). Self-serve add-on enable (settings/billing to billing enableAddon) only writes a TenantAddon row and emits ADDON_ENABLED. No Stripe subscription item is created, so the add-on is never billed, while platform MRR still books it. Only the platform-admin path (addon.service.ts ~324) creates the Stripe item. Fix: self-serve enable and disable add and remove the Stripe subscription item with proration, reusing the admin path. Tier 1 (money and Stripe), api. Lane: PC builder C, which owns #3098.
