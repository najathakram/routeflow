## Reported evidence

From SA-630 (#2554 5933774131), via Mac Lead. The endpoint POST /credit-notes/:id/void calls the legacy voidCreditNote (a pre-SA-436 second void door). It SKIPS the CREDIT_NOTE_RETURN_BACKED refusal, so it can void a live return's refund credit, and it skips the void reason and actor audit. Fix: keep the URL, delegate to voidWithReversal, delete voidCreditNote. Pins: a return-backed credit note answers 409; an audit row carries the actor. Money/audit, medium.
