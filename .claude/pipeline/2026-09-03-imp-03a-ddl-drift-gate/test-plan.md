# Test plan — PR-1 · Retire boot-time DDL; Prisma drift gate; DB-backed spec lane

Spec: `./spec.md`. Levels: unit / contract / integration. Every oracle is a concrete value known
independently of the implementation, so each test fails on **its own value** before the code
exists. **Red-gate scope = T1–T4 only** (all new files). A1–A5 are acceptance (integration) checks
run at close-out by an agent, never inside the red gate.

House rule for tests of NEW modules: load the module **inside the test body** with a guarded
`require` — `let mod: any = {}; try { mod = require("…") } catch {}` — then assert on it
(`expect(typeof mod.fn).toBe("function")`), so absence fails on an assertion, never a load error.
Test files import nothing from the implementation at module top level.

## Anti-vacuity notes

- T1 asserts a sorted array equality, not `length === 0`, so the failure message names the
  offending files.
- T3 case (c) is the one that distinguishes "reads any URL" from "prefers the proxy" — do not
  drop it to make the test simpler.
- T4 (c) exists so the CI path (non-local service host) is representable without weakening the
  local guard.
- No test asserts on log text or on `console.log` calls; T3 asserts on process exit status and
  stdout/stderr content of a child process, which is the script's contract.
