# Brief — PR-9 + PR-10 · Item 5: web unit/component tests (two light-loop PRs)

## Facts (surveyed)

`apps/web/package.json`: the only test devDependency is `@playwright/test`; scripts are
`test:e2e*` only; there is no `test` script, so `turbo run test` (the CI `verify` gate) runs
nothing for web. Next **14.2.35** (`next/jest` ships with it). Root `overrides` already pin
`jest`, `jest-runtime`, `jest-mock`, `jest-environment-node`, **`jest-environment-jsdom`**,
`@jest/*` to 30.2.0 (jsdom pinned though unused — advance preparation). API Jest = ts-jest/node
(package.json `jest` key); mobile = ts-jest/node, pure-logic `__tests__/**/*.test.ts` only, by
policy (`CLAUDE.md:14`). `apps/web/tsconfig.json` alias `@/*` → `./*`. `apps/web/lib`: 35 files /
5,416 lines; `api-client.ts` 297 (request interceptor attaches token + tenant `:101-103`; response
interceptor 401-refresh at `:147-232` with `/auth/refresh` skip and impersonation-token bypass,
localStorage refresh token), `tenant-host.ts` 70, `format.ts` 46 (Intl currency display; no
money math), `formatting.ts` 98. `z.object` sites: 0 in `lib`, 0 in `components`, **14 in
`app/**`** (form-colocated schemas). No `@testing-library/*` anywhere except mobile's RN one;
mobile's exact `react-test-renderer@19.2.0` pin must stay (Expo SDK 55). Pricing tests belong to
`@routeflow/pricing` (PR-4) — not here. Campaign gate (**verified**): `scripts/campaign-check.mjs:196-202` opens exactly three
hard-coded paths (`api.json`, `mobile.json`, `web-e2e.json`) and never enumerates the directory
or the Jest projects — a web Jest project without the reporter leaves it green, and a
`web.json` would be ignored. **Ruling: do not wire the reporter for web** (its artifacts are
bug-campaign evidence for T1 rows, which web unit tests don't prove); leave `campaign-check.mjs`
untouched.
