## Facts (sweep 2026-09-03, read-only)

`apps/web/lib/api` 48 files / 348 exported shapes; `apps/mobile/lib/api` 35 files / 268. Cross-app
duplicates by name: **134** — 49 identical, 46 near-identical (comments, field order, a nullable
widening, a named-vs-inline union with the same values), 39 divergent (different fields — NOT
shared). `packages/types` is imported by only `addons.ts` in each app; its `interface Order` and
`enum PaymentMethod` are shadowed by unrelated local declarations and unused by either `lib/api`.
~35 string-union types mirror Prisma enums; none live in `@routeflow/types`. **Drift found:**
mobile `VendorBillStatus` (`apps/mobile/lib/api/vendor-bills.ts:6`) has `"FULL"` — not a Prisma
value (`DRAFT|RECEIVED|PARTIAL|PAID|OVERDUE|VOID`); both apps omit `OVERDUE`; mobile `POStatus`
uses `"PARTIALLY_RECEIVED"` where Prisma `PurchaseOrderStatus` has `PARTIAL`; mobile
`BuyerPromotion.type` (`buyer.ts:317`) lacks `"BUY_N_GET_M"` that web (`buyer.ts:360`) and the
API carry. Intra-app duplicates: web `OrderTemplate` (2 divergent), `PriceType` (2 identical);
mobile `ChangeRequest*` ×4 (identical), `ExpiringAuthorization` (identical), `SalesBy*Row`
(divergent). The sweep's per-name table (with file:line for both sides and the classification) is
attached to this brief as `sweep.md` — it is the move list.
