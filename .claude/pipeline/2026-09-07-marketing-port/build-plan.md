## Standing rules for every package

- Live stack only: Next 14 App Router, React 18, Tailwind 3 (+ `tailwindcss-animate`), Radix (`dialog`, `dropdown-menu`,

  `app/[page]/page.tsx` and the components for body text). Preview-only lines are dropped (spec R2). Legal pages use

  `apps/web/components/brand/`. Tokens only under `.rf-marketing`. No edit to `app/globals.css` or the Tailwind configs

- Read `.claude/pipeline/design-system.md` for the live primitives and a11y baseline; `lessons`: L-072 (no hand-mirrored
