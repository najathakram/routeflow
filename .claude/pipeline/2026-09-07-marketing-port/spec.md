## Non-goals (explicit)

The workspace/dashboard half of the redesign; the auth screens' redesign (only their logo changes); dark mode; a real lead-capture endpoint (the mailto draft is the design; residual row); a designed OG image; pricing sourced from the billing catalog (stays static copy, as today); the mobile app's icons; API email/PDF logos (none embed the RouteFlow mark today); i18n of marketing copy; the three.js scene.

## Completeness sweep

- **States per surface:** loading (static pages: none beyond images' `next/image` placeholders), empty (n/a), error (`not-found.tsx` restyled; the contact form's invalid-email native validation), offline (n/a), unauthorized (n/a: all public), too-much-data (n/a), stale (n/a), concurrent (n/a).
- **Reverse of every action:** the mobile sheet closes on Escape/overlay/link click; the sign-in menu closes on select/Escape; the story's Restart resets quantity/route/delivered/paid; the contact form's "Start a new draft" resets.
- **Lifecycle of the core object (a marketing page):** create = the port; read = the routes; list = sitemap + nav; edit = code only; delete = the old files removed; permissions = public; audit = git; notification = none; export = sitemap/OG.

## Deploy-day / rollback

Deploy day: every visitor sees the new site immediately (no flag; public pages only). Existing tenants see the new mark in the app chrome and on their login screens where no tenant logo is uploaded. No data, migration or backfill. PWA icons refresh on the next manifest fetch. Rollback = revert the squash (one commit); no state.

## Residual rows to file at close-out

Designed OG image; lead-capture endpoint for the contact form; owner to supply the mark as SVG or ≥ 1024 px (the 512 icon is an upscale); confirm the `hello@routeflow.info` mailbox exists; the mobile web build has no marketing routes (the middleware allow-list makes phones see the desktop site instead); pricing copy vs the billing catalog; CLAUDE.md heavy-files policy amendment naming `public/brand` + `public/marketing` as required build assets.
