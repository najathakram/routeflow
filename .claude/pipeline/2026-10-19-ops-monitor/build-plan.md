# Build plan: live ops monitor (tools/ops-monitor)

Status: APPROVED (owner decision D-2026-10-19-live-ops-monitor, routeflow-specs). Lane: standard (tooling; no money/tenant/auth/schema paths).

## Preamble (why)
- **Problem / user:** the owner, the lead and 5 lanes on 3 machines cannot see one accurate, live picture of every bug, feature, spec, release, item and sub-item, and lanes have no reliable "what next". Four earlier attempts (Plane sync, GitHub Project #3 + reconciler, claude.ai registers, hand-kept DASHBOARD) died because each needed someone to remember to refresh a snapshot.
- **Workaround today:** the lead hand-edits WORK-REGISTER.md / DASHBOARD.md / state.json; they drift within hours.
- **Success signal:** a page on the PC where every panel shows a freshness age < 2 min, derived facts (PRs, CI, merges, deploys, bugs) appear with no human action, and every lane takes work with `rf next`. Baseline: freshest board was 03:40Z hand snapshot; Plane drift 380.
- **Non-goals:** writing to GitHub/Plane/Railway; editing product code; a hosted service; auth on the monitor (localhost by default; `--lan` is read-only); migrating Plane history; a Windows scheduled task.
- **Deploy day:** nothing in the product changes. Hooks start applying to every session once the PR merges; they fail open on their own errors and when the ops clone is missing (CI, cloud).
- **Rollback:** revert the PR; `RF_OPS_GATE=off` disables the Stop gate instantly; events stay in routeflow-specs untouched.

## Design rules (hard)
1. **Derived facts are never typed**: PRs, branches, CI, merges, visibility, deploys, bugs (registry on origin/master) and areas (file tree of origin/master) come from the collector only.
2. **Human facts are events**, typed once via `rf`, appended to `events/<machine>/<YYYY-MM-DD>.jsonl` (UTC date) in routeflow-specs. Append-only, one file per machine ⇒ git rebase never conflicts.
3. **Tool-owned clone**: all reads/writes of routeflow-specs go through `specsDir()` (default `~/.routeflow/ops/routeflow-specs`, cloned on first use from `specsRemote()`), never a human's checkout. All git ops on it run inside `withSpecsLock()`.
4. **Zero dependencies**: plain Node 20+ ESM (`.mjs`), `node:` built-ins only, child processes via `execFile` (no shell strings). No d3 (the map is hand-rolled SVG/CSS — deviation from the decision text, recorded: avoids a lockfile change that would collide with other lanes; no capability lost).
5. **No client/tenant names, ids or credentials in this repo.** Test fixtures use `acme`-style placeholders. Sensitive registry bugs (`sensitive: true`) are masked to `Security hardening item (details machine-local)` with no files/location everywhere (snapshot, views, UI).
6. Prettier style: double quotes, semicolons, printWidth 100, trailing commas.
7. Tests: `node:test` + `node:assert/strict`, files `tools/ops-monitor/test/*.test.mjs`, run `node --test tools/ops-monitor/test/`. Fixed `now` everywhere; no network; git integration tests use temp bare repos under `os.tmpdir()`.

## Packages (disjoint files; builders never commit)

### P1 — Core: fold, ids, next, store, CLI
Files: `tools/ops-monitor/lib/{ids,fold,next,store}.mjs`, `tools/ops-monitor/bin/rf.mjs`. Tests: `test/{schema,fold,next,ids,store,cli}.test.mjs`.
- `ids.mjs`: `newEventId(machine, now=Date.now(), rand=Math.random)` → `${machine}-${13-digit ms}-${4 chars [a-z0-9]}`; `nextItemId(state)` → String(max numeric item id + 1) (no numeric ids → "1"); `utcDate(ms)` → `YYYY-MM-DD`; `itemIdFromBranch(branch, knownIds:Set)` → tokens split on `/[\/_.-]/`; first token matching `/^b\d{1,5}$/i` (→ uppercase) or `/^\d{3,5}$/` that is in knownIds (B ids returned even if unknown); else null.
- `fold.mjs`: `fold(events, { bugs: Map<id,{title,state,severity}> } = {}) → State`. Sort by (ts, id). Each event: `validateEvent` fail → anomaly invalid-event, skip (lines that failed JSON parse arrive as `{__invalid: true, raw, file, line}` → invalid-event). Rules: item.new existing id → duplicate-item (first wins); events needing an item whose id is not in items: if `BUG_ID_RE` → create overlay item `{type:'bug', title: bugs.get(id)?.title ?? id, status: 'planned', overlay: true, source: 'registry'}` then apply; else unknown-item, skip. item.edit merges fields (links merged/deduped, never replaced). claim: held by another lane and !steal → anomaly claim-conflict + `item.claimConflict=[holder, newLane]` (holder kept); else claimedBy=lane, claimedAt; data.branch → links.branches. release by holder → claimedBy null. status → item.status; a DONE status auto-releases the claim. blocked/unblocked set/clear item.blocked. link merges. push: item = ev.item || item whose links.branches has branch || itemIdFromBranch(branch, ids); if found, add branch to links; lane = ev.lane || claimedBy of item; record in pushes. pr: item = ev.item || item linked to data.branch || item whose links.prs has number; add number. Every event: lanes[ev.lane] lastEventAt/lastEventKind (lane non-null), machines[machine]=ts, item.updatedAt + history (cap 50). After all: children = ids whose parent === id (parent unknown → keep field, no anomaly); lanes[x].claims recomputed from items.
- `next.mjs`: `rankCandidates(state, laneId, config, { now })` and `pickNext(...)` → `{ item, reason } | null`. Candidate: status ∈ PICKABLE_STATUSES; type ∉ {release, epic}; not blocked; claimedBy null; no child that is itself not DONE (prefer leaves); and (item.lane === laneId OR (item.lane null AND areaMatches(item, lane.areas))) — `areas` entries: `"*"`, `"domain:<id>"` (matches item.area === `domain:<id>` or an area whose domain is id via `areaDomain` from `lib/areas.mjs`), or an exact area id (`api:invoices`). Sort: priority P0→P3; train order (R1 < R2 … by number; none = 99); eta via `parseEta(eta, now)` from `lib/ids.mjs` asc (null last); numeric id asc, then string id. reason = `"P1 · R2 · assigned to pc-lane"` style. `laneNow(state, laneId)` → ids claimed by lane ∪ unclaimed items with lane === laneId and status ∈ {building, review, ready, shipping}.
- `store.mjs` (IO): `exec(cmd, args, {cwd, timeoutMs=60000, env})` → Promise<{code, stdout, stderr}> (never rejects; ENOENT → code 127). `withSpecsLock(fn, {home})` — `mkdir` lock dir `<opsHome>/specs.lock`, stale after 120 s, retry every 100 ms up to 30 s, always removed in finally. `ensureClone({dir, remote})` — clone if `<dir>/.git` missing. `syncSpecs(dir)` — `git pull --rebase --quiet` (tool-owned clone) then `git push` if ahead. `readAllEvents(dir)` — every `events/*/*.jsonl`, one JSON per line, invalid lines as `{__invalid:true, raw, file, line}`. `loadBugIds(repoRoot)` — `git ls-tree --name-only origin/master .claude/campaign/bugs/` → Set of `B###`. `appendEvents(events, {dir, push=true, retries=5})` — under lock: sync, fold current events, `validateAgainstState` each (below), write lines to `events/<machine>/<utcDate(ts)>.jsonl` (mkdir -p), `git add` those files, `git commit -m "ops(<machine>): <kind> <item|-> [+N]" -- <files>`, push; on rejection `git pull --rebase` and retry; if after the pull an `item.new` id now collides with an event from another machine, `git reset --soft HEAD~1`, re-allocate with `nextItemId`, rewrite the line, recommit (only possible because the commit is unpushed). Returns `{ events, pushed, attempts, warnings }`; push failure that is not a rejection (offline) → `pushed:false`, commit stays local (next sync pushes it).
  `validateAgainstState(ev, state, {bugIds})` → errors[]: item.new id must not exist (and not be a bug id); parent/train if set must exist (train must be type release); other kinds with an item: id must be in state.items or bugIds (refuse unknown ids); claim held by another lane without `steal` → refused "held by <lane> since <ts>; pass --steal to take it".
- `bin/rf.mjs` — usage below; `#!/usr/bin/env node`; exits 0 ok, 1 refused (validation), 2 usage, 3 committed but not pushed. `--json` prints machine output. `--no-push` skips push. Actor = `RF_ACTOR` env || lane || `${machine}:${basename(cwd)}`.
```
rf event <kind> [<item>] [--lane L] [--status S] [--note T] [--by X] [--unblocker Y] [--ref R] [--summary S]
         [--question Q] [--answer A] [--recommended R] [--text T] [--pr N]... [--branch B]... [--url U]...
         [--sha S] [--repo O/R] [--action A] [--number N]
rf claim <id> [--lane L] [--branch B] [--steal]       rf release <id> [--lane L]
rf status <id> <status> [--note T]                    rf block <id> --by X [--unblocker Y]   rf unblock <id>
rf next [--lane L] [--claim] [--json]                 (top item + up to 4 runners-up)
rf item new --title T --type X [--priority P] [--status S] [--lane L] [--train R1] [--area A] [--parent ID] [--eta E] [--gate G] [--id ID]
rf item edit <id> [--title …] [--priority …] … (any item field flag)    rf item show <id> [--json]
rf ls [--lane L] [--train R] [--status S] [--type T] [--open] [--json]
rf whoami [--machine M]   (prints machine, lane, specs dir, clone state; --machine writes <opsHome>/machine)
rf backfill [--dry]       (P3's lib/backfill.mjs runBackfill)
rf views [--dry] [--no-push]   (P3's lib/views.mjs writeViews)
rf doctor                 (git, gh auth, clone, config, bug ids, last push — one line each)
```
  `--lane` values pass through `normalizeLane`. `rf next --claim` claims the picked item.

- `collector.mjs`: pure parsers + `createCollector({ repoRoot, specsDir, exec, now = Date.now, intervals, onUpdate, log })` returning `{ start(), stop(), runOnce(name), sources }`. Source state `{ ok, at:number|null, tried, error, data, intervalSec }`; a failing run keeps the last good `data` and sets `ok:false, error`. Sources (intervals sec): `specs` 30 (`syncSpecs` + `readAllEvents` + `loadConfig`), `github` 60 (`gh api graphql -f query=<Q>`; Q below), `branches` 120 (`git fetch origin --quiet` on every 5th run, skipped when RF_OPS_LIGHT=1; `git for-each-ref refs/remotes/origin --format=%(refname:short)%09%(objectname)%09%(committerdate:iso-strict)`; branches with date ≤ 14 days, excluding `origin/master`, `origin/HEAD` and any whose sha is a merged PR's head; changed files `git diff --name-only origin/master...<sha>` cached by sha, max 80 diffs per run), `bugs` 120 (`git rev-parse origin/master:.claude/campaign/bugs` → tree sha cache; `git ls-tree` + `git cat-file --batch` front matter), `areas` 300 (`git ls-tree -r --name-only origin/master -- apps packages scripts tools .claude .github docs`, cache by commit sha), `railway` 120 (`railway status --json` in repoRoot; ENOENT → `error:'railway CLI unavailable'`). Each run of a source then calls `onUpdate(name)`. Never throws out of a timer.
  Graphql Q (repository najathakram/routeflow): `visibility`; `open: pullRequests(states:OPEN, first:60, orderBy:{field:UPDATED_AT,direction:DESC}) { nodes { number title isDraft headRefName headRefOid baseRefName updatedAt url commits(last:1){nodes{commit{statusCheckRollup{state}}}} files(first:100){nodes{path}} } }`; `merged: pullRequests(states:MERGED, first:50, orderBy:{field:UPDATED_AT,direction:DESC}) { nodes { number title headRefName mergedAt url baseRefName mergeCommit{oid} } }`; `master: ref(qualifiedName:"refs/heads/master"){ target { ... on Commit { oid committedDate messageHeadline statusCheckRollup{state} } } }`.
  Parsers (exported, tested on fixtures): `parsePrGraphql(json)`, `parseForEachRef(text)`, `parseBugFrontMatter(text)` → `{ id, title, severity, state, sensitive:boolean, files:[], location, closed }` (YAML-ish `key: value` lines between the first two `---`; `files` space-separated), `isOpenBug(b)` (closed empty AND state ∉ {done, already-fixed, refuted, closed, fixed, duplicate, wontfix}), `maskBug(b, area)` → sensitive ⇒ `{ id, title: "Security hardening item (details machine-local)", severity, state, area: null, domain: null, sensitive: true }` else `{ id, title, severity, state, area, domain, sensitive:false }` (area = fileToArea(first file) else null), `parseCatFileBatch(buf)` (headers `<sha> blob <size>\n<content>\n`), `parseRailwayStatus(json)` → `[{ service, status, sha, createdAt }]` for production environment service instances whose name starts with `@routeflow/` (`latestDeployment.status`, `.meta.commitHash`, `.createdAt`).
- `reconcile.mjs`: imports `parseEta` and `itemIdFromBranch` from `lib/ids.mjs`. `reconcile({ state, prs, branches, sources, config, now }) → alarms[]`:
  - `status-behind-merge` (error): item status ∉ DONE and ∉ {idea} with a linked PR (links.prs or prEvents) present in `prs.merged` with base master → "PR #N merged <age> ago but item is <status>"; suggest `rf status <id> live`.
  - `untracked-pr` (warn): open PR whose number/branch maps to no item (links.prs, links.branches, `itemIdFromBranch`) → suggest `rf event link <id> --pr N`.
  - `untracked-branch` (info): branch dated within 48 h, no PR, no item.
  - `claim-conflict` (error): every item with claimConflict.
  - `lane-silent` (warn): lane with ≥1 claim and (now − lastEventAt) > laneSilentMin.
  - `past-eta` (warn): item not DONE, parseEta < now.
  - `stale-source` (error for specs/github, warn otherwise): never ok, or now − at > intervalSec × sourceStaleFactor.
  - `anomaly` (error): one per state.anomalies entry (kind in message).
  Alarm id = `${kind}:${item ?? pr ?? branch ?? lane ?? source}`; sorted error → warn → info, then id.
- `snapshot.mjs`: `buildSnapshot({ sources, config, now, machine }) → Snapshot` (contract above). Uses fold (P1) with the bugs map, links PRs/branches to items (same mapping as reconcile, exported helper `linkItemFor({number, branch}, state)`), PR/branch `areas` = unique fileToArea of their files, item domain = areaDomain(item.area) when area is an area id, `item.area` `domain:<id>` → id, else guessDomainFromText(title). ### P3 — Backfill + generated views
Files: `tools/ops-monitor/lib/{backfill,views}.mjs`. Tests: `test/{backfill,views}.test.mjs`, fixtures `test/fixtures/{register.md,plan.md,owner-queue.md,board-state.json,dashboard.md}` (acme placeholders only; 6-10 rows each, shaped exactly like the real files described here).
- Real source shapes (in the specs clone): `register/WORK-REGISTER.md` rows `| ID | Title | Type | Priority | Status | Lane | Train | Gate | ETA | Links | Updated |`, ID numeric; links cell like `[item](items/525.md) [#3467](https://github.com/najathakram/routeflow/pull/3467) merged`. `releases/PLAN-2026-10-18.md` "## Trains" table `| Train | Members | Lanes | Gates | ETA (window) |`, first cell `**R1 window 2: back office + product S-fixes**`. `priorities/OWNER-QUEUE.md` tables `| # | Item | Register | Recommended answer | Why |` with `#` like `N1`. `local-assets/board/state.json` (in boardDir): `{ asOf, trains:[{order,train,name,members,lanes,target,state,next}], lanes:[{lane,machine,model,now,next}], owner:[{ask,when,recommended,state}], problems:[{problem,impact,fix,state}] }`.
- Pure parsers: `plain(md)` (strip links → text, `**`, `` ` ``, `<br>`); `parseRegister(md, config)` → drafts `{ id, fields }`: type `fix→bug`, known TYPES kept, else `chore`; priority P0-P3 else P2; status = first STATUSES word found at the start of the cell (lowercased) else `planned`; lane = normalizeLane(cell); trainLabel = plain train cell (≤120); train = `R\d` token in train cell; gate (≤400), eta (≤80) plain; links.prs from `/pull/(\d+)` and `#(\d{3,5})`; area = `domain:<guessDomainFromText(title)>` or null; source `register`; title plain ≤300. `parsePlanTrains(md)` → `[{ id:'R1', title, membersText, lanes, gates, eta }]`; `trainMembers(text, knownIds)` → ids from `rows? (\d+)(?:[/,] ?(\d+))*`, `row (\d+)`, `\bB\d{2,5}\b`. `parseOwnerQueue(md)` → `[{ key:'N1', title, register: ids, recommended, why }]` from every table with a `Recommended answer` header. `parseBoardState(json)`.
- `buildBackfillEvents({ register, plan, ownerQueue, board }, { state, config, machine, now, actor:'backfill' })` → events (use `newEventId`): trains first (`R1`… type release, title from plan/board, status from board state: `proofs|fixing|testing|building → building`, `waiting|planned → planned`, `shipped|live → live`, else planned; eta = board target or plan ETA; members = trainMembers ∪ register rows whose `train` is that R; gate = plan gates), then register rows (skip ids already in state), then owner-queue decisions (type decision, lane owner, priority P1, status planned, gate = `Recommended: …`, related = register ids, tags `['owner-queue', key]`) and board owner asks (decision, lane owner, gate recommended, eta when, tags `['owner-ask']`), then board problems (incident, P0, status building, gate = fix, tags `['problem']`). New ids = sequential from `nextItemId(state)`. Idempotency: skip an owner/problem draft whose normalized title (lowercase, collapsed spaces) equals an existing item title. Bugs are NOT imported (derived live from the registry).
- IO `runBackfill({ specsDir, boardDir, dry })`: read sources, fold existing events, build, `appendEvents` (one commit) unless dry; record `ops/state/backfill.json` `{ at, registerSha256, counts }` (sha256 of the register file as read). Returns counts.

### P5 — Hooks (milestone 2, after P1)
Files: `.claude/hooks/ops-post-push.mjs`, `.claude/hooks/ops-stop.mjs`, `tools/ops-monitor/lib/turn-actions.mjs`, `.claude/settings.json` (add entries only), test `tools/ops-monitor/test/hooks.test.mjs`.
Both hooks follow `.claude/hooks/stop.mjs` / `scripts/work/claude-hook.mjs`: plain Node ESM, paths resolved from the script's own location, every exported function above an `── IO` marker is pure and tested directly, and **any exception, missing file, missing ops clone, or `RF_OPS_GATE=off` → exit 0** (one stderr line at most for the Stop hook; nothing at all for PostToolUse). Never slow the tool call: PostToolUse does its git reads with 2 s timeouts and spawns the recorder detached.
- `lib/turn-actions.mjs` (pure + tiny IO): `actionsFile(home, sessionId)` → `<opsHome>/turn-actions/<sanitized sessionId>.jsonl`; `appendAction(file, action)`; `readActions(file)`; `archiveActions(file)` (rename to `.done-<ms>`; keep last 5).
- `ops-post-push.mjs` (PostToolUse, matcher Bash). stdin `{ session_id, cwd, tool_input: { command }, tool_response: { stdout, stderr, interrupted } }`. Pure `detectOpsActions(command, response)` → `[{ kind: 'push', remote, refspec } | { kind: 'pr', action, number|null }]` using `commandSegments` from `scripts/work/claude-hook.mjs` (import it; it already splits on `&& || ; | \n`): a segment whose tokens (after an optional `git -C <dir>` / `git -c k=v`) start `git push` → push (remote = first non-flag arg, refspec = second); `gh pr (create|ready|merge|close|edit)` → pr (number = first all-digit arg, else a `/pull/(\d+)` in stdout). No action when `interrupted` or when stdout+stderr match `/\b(rejected|fatal:|error:|failed to push|Everything up-to-date)\b/i` (push) or `/^(GraphQL|HTTP \d{3}|error|failed)/im` (pr). IO: for each push, resolve in cwd `git rev-parse --abbrev-ref HEAD`, `git rev-parse HEAD`, `git remote get-url <remote|origin>`; only when the URL matches `/najathakram\/routeflow(\.git)?$/i` (never routeflow-specs) — branch = refspec's destination (`HEAD:refs/heads/x` → x, `x:y` → y, `x` → x) else HEAD's branch. Append `{ ts, kind:'push', branch, sha }` / `{ ts, kind:'pr', action, number, branch }` to the session's actions file, then spawn detached `node tools/ops-monitor/bin/rf.mjs event push --branch B --sha S --repo najathakram/routeflow --quiet` (or `event pr --number N --action A --branch B`) with `RF_ACTOR` = `hook:<session prefix 8>`; `stdio: 'ignore', windowsHide: true`, `unref()`.
- `ops-stop.mjs` (Stop). stdin `{ session_id, cwd, stop_hook_active }`. Pure `evaluateGate({ actions, state, now })` → `{ ok: true } | { ok: false, missing: [{ action, why, fix }] }` where:
  - push → needs a `state.pushes` entry with the same sha (or same branch with ts ≥ action.ts − 5 min) — else `why: 'push not recorded'`, `fix: 'node tools/ops-monitor/bin/rf.mjs event push --branch <b> --sha <s> --repo najathakram/routeflow'`; and that push's `item` non-null — else `why: 'branch <b> is not linked to an item'`, `fix: 'rf event link <id> --branch <b>'` (or `rf item new …`).
  - pr create/ready → needs a linked item for the PR number or branch (same rules).
  - pr merge → needs a `status` event (in item history) for the linked item with ts ≥ action.ts − 5 min — else `why: 'PR #N merged but item <id> has no status event'`, `fix: 'rf status <id> shipping'` (or live).
  - close/edit → no obligation.
  IO: read the session's actions file (none → exit 0); load state by `fold(readAllEvents(specsDir()))` with the bug overlay (no network); if a push is "not recorded", re-read up to 5 × 1 s (the detached recorder may still be running). ok → archive the actions file, exit 0. Not ok → print to stderr `Ops gate: <n> action(s) this turn have no matching event:` + one line per missing (`- <why> → <fix>`) + `(RF_OPS_GATE=off disables this gate; it fails open on its own errors)`, exit 2. Loop guard: keep `<file>.blocks` = count of consecutive blocks for the same `missing` hash; on the 3rd consecutive block for the same hash, allow (exit 0) with a loud stderr line and archive the actions file (never brick a session).
- `settings.json`: add `{ "matcher": "Bash", "hooks": [{ "type": "command", "command": "node .claude/hooks/ops-post-push.mjs" }] }` to PostToolUse and `{ "hooks": [{ "type": "command", "command": "node .claude/hooks/ops-stop.mjs" }] }` to Stop — append entries, change nothing else.
- Tests (`hooks.test.mjs`): detectOpsActions table (`git push -u origin feat/x`, `git -C ../a push origin HEAD:refs/heads/fix/b12`, `echo git push` → none, chained `git add . && git push`, rejected push → none, up-to-date → none, `gh pr merge 3515 --merge`, `gh pr create … ` with URL in stdout); evaluateGate (recorded+linked → ok; unrecorded → missing; unlinked → missing with link fix; merge without status → missing; merge with status → ok); spawn the two hooks as child processes with crafted stdin and a temp `RF_OPS_HOME`: garbage stdin → exit 0; `RF_OPS_GATE=off` → exit 0; no actions file → exit 0; unmet → exit 2 with the fix text; third identical block → exit 0; post-push with a non-routeflow remote → no actions file written.
