## #4015 `2527c8f745` till doors: one Enter commits nothing nobody chose (SA-1067 PR-1, T1; A-1 to A-4)

- New `lib/armed-enter.ts` `useArmedEnter(key)` returns `{ press(needsSecond, commit), armed, disarm }`: a value that needs a second Enter arms on the first and commits on a second Enter on the SAME `key`; any change of `key` ends the arm, even if the same value comes back. Pointer actions and focused buttons do not go through it.
- M1 `components/PriceHistory.tsx`: the panel opens with no row chosen (`active` starts at -1; Enter needs a chosen row; the pointer no longer chooses, CSS hover only; a unit-tab change clears it; the chosen row scrolls into view). The key handler is lifted to the popover shell through a new `keyRef` prop (focus lands on the shell, so keys never reached the inner body). Covers every mount (counter, order builder, order detail).
- M2a `orders/_components/CounterLinePriceEdit.tsx`: the first Enter in the price dialog arms (mode, value and reason shown, "Press Enter again to apply."), a second Enter on the same applies; clicking Apply, or Tab to Apply and Enter, commits at once. New error `OVER_LIMIT` ("That's over the limit. Enter $1,000,000.00 or less.").
- M2b `orders/_components/CounterSaleScreen.tsx` and `orders/[id]/_components/PickupCompleteDialog.tsx`: `lib/counter-sale.ts` new `TENDER_ARM_OVER = 100` and `tenderNeedsSecondEnter(total, tendered)` (a tender $100 or more over the total arms "Press Enter again to complete the sale."; a normal tender still completes on one Enter). `lib/counter-part-pay.ts` new `PLAIN_MONEY` (`/^(\d+\.?\d{0,2}|\.\d{1,2})$/`) and `tenderAmount(text)` (digits with at most two decimals read as money, anything else reads as 0 so `TENDER_SHORT` refuses it; a typed half cent such as 10.005 is now refused, rounding stays in `counterPaymentAmount`). Both tender parsers call `tenderAmount`, and `partPayAmountProblem` uses the same pattern. A part-pay amount over the total was already refused (a guard, not an arm).
- M3 `lib/counter-price-edit.ts`: `resolveCounterPriceEdit` refuses a price over `MAX_UNIT_PRICE` (from `@routeflow/pricing`) as `OVER_LIMIT` with `max`, no preview.
- M4 `CounterSaleScreen.tsx`: the desktop scan-focus key listener routes `0-9A-Z` (a wedge code that starts with a capital letter used to lose it); known narrowing L4: with Caps Lock on, a capital G then H on a plain button now types `GH` into the scan box and does not navigate.
