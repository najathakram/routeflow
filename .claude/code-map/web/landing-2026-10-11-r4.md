## Digital receipt and one receipt model (SA-751r, SA-762r)

- `lib/counter-receipt.ts`: `CounterReceiptLine` / `CounterReceiptModel` are now aliases of the SHARED `ReceiptLine` / `ReceiptModel` (`@routeflow/types` `api/receipt.ts`), the same type the API email renderer builds; `adjustmentLabel` is pricing's `taxRowLabel`. NEW `receiptCustomerName(customer)` (nothing for no customer or the system walk-in record; one rule for the live receipt and the reprint). The live receipt takes Tax, the rate candidate, `change`, and the stored line price facts (`lines`) from the SERVER response (`CounterSaleResponse.tax` / `taxRatePercent` / `lines` / `change`), strikes a list price through pricing `receiptLineAmounts` (the invoices' own rule; with `hideOriginalPrice` from `GET /settings` nothing is struck), and names a rate only through `explainedTaxRatePercent`; an older server that sends no tax prints no Tax row; the settings rate is no longer a money source here. The reprint shows the row's `cashTendered` and the server's `change` as given (null = no Change row, 0 = "Change $0.00"); an entered tender is a fallback only for a paid sale the server stored no tender for. A reprint keeps line notes.
- NEW `lib/email-receipt.ts`: `RECEIPT_EMAIL_COPY` (fixed copy; a server message is never shown), `isValidReceiptEmail`, `receiptEmailPrefill(...)`, `ReceiptEmailFailure`, `isFinalReceiptEmailPhase`, `receiptEmailFailureOf(err)` (maps `RECEIPT_EMAIL_*` codes). NEW `lib/api/receipts.ts` `sendOrderReceiptEmail(orderId, to)` (`POST /orders/:id/receipt`). NEW `orders/_components/useEmailReceipt.ts` `useEmailReceipt({orderId, prefill})` (phases `idle | sending | sent | failure`, offline-aware, nothing queued), `EmailReceipt.tsx` `EmailReceiptButton` (secondary, beside Print) and `EmailReceiptRow`, `CounterReceiptActions.tsx` `CounterReceiptActions` (Print primary, Email receipt, Return items, New sale; a walk-in opens empty, a named customer's address is the pre-fill, never an auto-send). `CounterTodaysSales.tsx` reprint view gains the same email row (a voided sale is a final state; Escape closes the row first).
