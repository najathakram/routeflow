## #4064 `3f63d21234` a return's reason, note and price are one per product; the focused box stays in view (SA-1079, BR-16)

- Rule: the return request holds ONE item per product (`mergeDuplicateProductItems`), so reason, note, credit price, override reason and the already-returned reason belong to the product, not the row. Boxes and pieces stay per row.
- `packages/returns/src/inline-return-state.ts`: new `PRODUCT_WIDE_FIELDS` (`reason`, `note`, `creditUnitPrice`, `overrideReason`, `alreadyReturnedReason`, typed `satisfies readonly (keyof InlineReturnLineDraft)[]`); `patchReturnLine(lines, at, patch)` applies the patch to row `at` and writes the product-wide keys in it to every other row of the same product (an unknown index returns a copy); `adoptProductValues(lines, line)` gives a row put back by Undo the product-wide values its product's ruling row (`rulingLineIndex`) holds now, or its own when no row is left.
- `app/(dashboard)/returns/_components/InlineReturnSection.tsx`: the line edit goes through `patchReturnLine`; Undo re-inserts `adoptProductValues(prev, line)` so it never brings back an older price or reason. `LineRow` props change: `followsFirst`, `rulingIsFirst` and `firstReason` are gone; `isRuling` (the row whose quantity the capture counts first, the only row that opens its options by itself) and `rowCount` (rows of the product on screen) replace them. With 2 or more rows the product-wide labels read "(both rows)" or "(all N rows)". The options auto-open only for the ruling row. The text-field grid is `grid-cols-1` when `rowCount > 1`, else `grid-cols-2`, with `data-testid="return-line-text-fields"` (W-785: the long label does not fit half a phone column).
- BR-16: `keepFocusedFieldInView()` (module-level, `STICKY_BAR_ROOM = "6rem"`) sets `scroll-margin-bottom` on the focused input/select/textarea and calls `scrollIntoView({ block: "nearest" })`; a layout effect in `LineRow` runs it when the row goes from closed to open (a price typed on another row of the product opens the ruling row and pushed the box being typed in down the page, under the edit page's sticky Save / Cancel bar). Imports `cn` from `@routeflow/ui/web`.
- Tests: `packages/returns/src/inline-return-state.spec.ts` (patch spreads product-wide keys only, adopt on Undo, `PRODUCT_WIDE_FIELDS` pin), `returns/_components/InlineReturnSection.one-step.test.tsx` and `InlineReturnSection.test.tsx` (labels, one value per product, focus kept in view).
