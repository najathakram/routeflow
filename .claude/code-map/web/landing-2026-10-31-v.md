## #4026 `69f9be15fe` the till shows the remembered price the server books (SA-1068)

- `orders/_components/useCounterReprice.ts`: reads the customer's price history (`useCustomerPriceHistory`, the server's own read) and exposes `rememberedOf(productId)`; a changed remembered price re-prices the cart (`rememberedSig`). While that read is pending or failed the prices are unconfirmed (`unconfirmed`), Pay waits (`blocked`) and Retry refetches it; a walk-in has no customer, so no read. After a sale the history query for that customer is invalidated so the next sale reads the renewed memory. Undo (SA-1068 A-2): a line with a remembered price on either side of the change stays where the rule put it, because an unedited line sends no price and the server books today's rule.
- `orders/_components/counter-sale-reprice.ts` `repriceLines(lines, tierFor, layerOf, rememberedOf?)` and `counter-sale-scan.ts` pass `remembered` into `customerLinePrice`; `priceType` now comes from the helper (`lp.priceType`), and a line carries `remembered: true` only while it sits at the remembered above-list price. `lib/api/counter-sale.ts` and `lib/counter-ship-handoff.ts` type `priceType` as `CustomerLinePrice["priceType"]`.
- `orders/_components/CounterLineRow.tsx`: a "Last price" chip (`line-last-price-chip`) on a remembered line with no manual override. `CounterSaleScreen.tsx` threads `rememberedOf`.
- Tests: `orders/_components/counter-sale-remembered.test.ts`, `useCounterReprice.remembered.test.tsx`, `useCounterReprice.undo.test.tsx`, `CounterLineRow.last-price-chip.test.tsx`, `lib/api/counter-sale.history.test.tsx`; the `CounterSaleScreen.*.test.tsx` and `counter-sale.review` / `counter-sale-reprice.price-layer` tests mock the history read.
