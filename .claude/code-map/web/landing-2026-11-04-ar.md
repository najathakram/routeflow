## #4188 `e78cd762ba` the driver's settle footer and the office settle card (SA-1098 PR-S)

Rule: the web reads the server's expected figure and the shared pricing rule; it never re-derives "does this run hold money".
- `components/RunSettlementForm.tsx` (driver, office and amend modes): the server's figure on two lines, one count, a reason only past a cent, errors per the A-1 table. A driver's settle then finish are two writes: a retry after a failed finish sends only the finish, and a lost settle response (`RUN_ALREADY_SETTLED`) carries on. The submit latch is a ref set before the first await, so two taps in one tick send one settlement. The form and the office page run the run hooks with `localErrorToast`, so a refusal raises one message.
- `app/(dashboard)/routes/my-runs/RunSettleFooter.tsx` and `page.tsx`: one primary, Settle your run, once no stop is left and the run holds cash or checks with no settlement on record. `lib/run-settlement-controls.ts` (`driverRunFooter`, `officeSettlementControls`, `parseCount`) decides it by calling pricing's `shouldForceSettlement`; Finish route shows only when nothing is unsettled (`finishRouteBlocker` reads the same `driverRunFooter`). `RUN_HAS_STOPS_LEFT` shows "A stop was reopened. Finish it, then settle." and refetches the run so the footer goes back to the stop. `parseCount` takes a plain amount only (digits, thousands commas in threes, at most two decimals, at most `SETTLE_MAX_COUNT`); `1e3`, `0x10`, `12,50`, `60.004` and `$` read as empty.
- `my-runs/run-lifecycle.ts` now holds `finishRouteBlocker` and `finishedRunView` (moved out of `page.tsx`, no behaviour change): Next types a page file's exports, so those exports broke web `check-types` in any tree holding a generated `.next/types`; a pin holds `page.tsx` to its default export.
- `app/(dashboard)/routes/[id]/page.tsx`: the office run page card shows Settle run, Finish run or Amend per A-1's table (operators only); Settle is not offered on a COMPLETED run with money and no note, and CANCELLED keeps it. `lib/api/routes.ts` carries the settle call.
- Tests: `components/RunSettlementForm.test.tsx`, `RunSettlementForm.one-toast.test.tsx`, `my-runs/RunSettleFooter.test.tsx`, `my-runs/page.settle-footer.test.tsx`, `my-runs/page.lifecycle.test.tsx`, `routes/[id]/page.settlement-copy.test.ts`, `lib/run-settlement-controls.test.ts`, `lib/run-settlement-controls.shared-rule.test.ts`.
