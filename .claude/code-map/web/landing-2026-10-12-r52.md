## R5.2: order edit sends the revision it loaded; stale 409 reload and per-field rebase (row 372)

- `app/(dashboard)/orders/[id]/_components/OrderStaleNotice.tsx` NEW `useOrderStaleRevision(order, editing, onRebase?)` -> `{expected, baseLines, baseFee, feeChanged, capture, ownsToast, node}`. The base `{rev, lines, fee, credits}` is captured when edit mode opens (keyed on `editing` only, never the live refetch, no fallback to the live revision).
- Same file: `capture(err)` matches 409 `API_ERROR_CODES.ORDER_REVISION_STALE`; `ownsToast` is the `localErrorToast` predicate; `node` is the fixed-copy notice (`ORDER_STALE_COPY`, `order-stale-notice`) with Reload (refetch `["orders", id]`, `onRebase(fresh, base)`, fresh becomes the new base).
- `orders/[id]/_components/order-edit-rebase.ts` NEW, pure, generic over the page's `RebaseDeps.seed`: `rebaseEditItems(items, base, fresh, deps) -> {items, dropped, conflicts}`; private `mergeRow(edit, base, fresh)` is a per-field three-way merge: user changed nothing -> fresh; nobody else did -> user row; both -> fresh plus the user's own fields, a field both changed takes fresh and counts.
- `mergeRow` invariant: `DENOMINATION_KEYS` (product, substitute, unitLabel, unitsPerBox, boxSplit, isUnlisted). When both sides changed a line and either touched one, the fresh row wins whole (only `cancelled` kept) and is counted, so a qty never crosses a unit/pack/product change. `UI_ONLY_KEYS` and `PRODUCT_ONLY_KEYS` are never evidence of an edit.
- `rebasePendingDeletes(ids, fresh)` drops queued deletes of vanished lines (each would 409). `rebaseOnReload(state, fresh, base) -> n` also rebases the shipping fee (user-alone change kept, both changed -> server's, counted) and applied credits (the full desired set: another operator's set replaces the selection, `creditsTouched` reset); the page toasts when `n > 0`.
- `orders/[id]/page.tsx`: line diff is `buildItemUpdates(editItems, stale.baseLines() ?? order.lineItems)`, `feeChanged` via `stale.feeChanged`, `expectedRevisionNumber: stale.expected()` on BOTH Save and Publish-from-edit; `guardError` runs `stale.capture`. `lib/api/orders.ts` `Order.revisionNumber?`; `useUpdateOrderItems` input +`expectedRevisionNumber?`.
- Pins: `order-edit-rebase.test.ts`, `OrderStaleNotice.test.tsx`, `stale-revision-wiring.static.test.ts`.
