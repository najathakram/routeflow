A scanned 12-digit code is judged as one whole number and refused with "That is more than one line can hold. The most is 100,000 pieces." The unit box refuses unparseable text instead of sending 0. Tests: `CounterSaleScreen.qty-hold.test.tsx`, `CounterLineRow.qty-refusal.test.tsx`, helper `test-utils/type-qty.ts`, e2e `72-counter-pos-stack.spec.ts`.
