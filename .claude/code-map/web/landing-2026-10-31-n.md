## #4038 `e74853b41d` the order builder shows the remembered price it books (W-1056, SA-1068 A-3 to A-7)

- Rule: the builder prices a plain line from the customer's remembered price (`stickyPrice` only) the way the server books it; a line at the memory shows it and sends no price, a price typed at the tier is sent. The server's rule is unchanged.
- `orders/_components/CreateOrderModal.tsx`: `priceHistoryRead` (the query, for `isPending`) and `priceHistory`; `rememberedOf(productId)` = `priceHistory?.[productId]?.stickyPrice` is the only memory read (M17); `memoryOf(li)` = `customerLinePrice({ ..., remembered })` price when `lp.remembered`, else undefined (pack only, no layer row). A new line with no pre-fill starts at the memory as MANUAL with `prefillCustomerId` set (M20). Clearing a price returns to the memory (M19, M26). A typed price calls `applyTypedPrice(li, value, { memoryMayBook: priceHistory === undefined || memoryOf(li) != null })` (M18). The customer effect now passes `remembered`, lists `priceHistory` in its deps, and a line linked to its customer (`prefillCustomerId`) follows the customer until a person prices it (M27); with `scan_v2` off a resume holds such lines until its own re-price has run (M28, `repriceAfterResumeRef`).
- Resume: `resumePricesReady` also waits for `!priceHistoryRead.isPending`; when the read settled with `priceHistory === undefined` (a failed refetch keeps cached data, so the test is on data, not on `isError`) the effect sets `pricesNotRefreshed` and keeps the lines as parked (A-4). `lib/order-draft/resume.ts` `repriceResumedLines(lines, tierFor, layerOf?, rememberedOf?)` (M14).
- `lib/staff-price-override.ts` `applyTypedPrice(li, typed, opts?: { memoryMayBook })`: a price typed at the tier is still sent (DISCOUNTED below list, else MANUAL) when a memory may book.
- `lib/order-line-unit.ts`: `applyLineUnit` ctx gains `remembered`; `restorePack` returns the memory (MANUAL) for a derived Piece start and a line back on its pack (M22, M24); `customerLineSpecial(lp, keep?)` returns `keep` when `lp.remembered`, so the tier stays the baseline (M21). `lib/default-unit-line.ts`: `applyUnitToLines`, `applyUnitToLinesDetailed` and `startLineOnDefault` take `remembered`; `DefaultUnitDeps.rememberedOf` is required (M25). `lib/hooks/useDefaultUnitResolver.ts` takes it as its fifth argument; `invoices/new/page.tsx` passes `() => undefined` (a manual invoice carries its price as typed).
