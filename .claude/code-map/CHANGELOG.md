Both are now event-name allow-lists. `EXPECTED_SHA` and the checkout `ref:` are both `github.event.deployment.sha || github.sha` — they must stay identical or the gate's `git diff` compares the wrong trees. ⚠️ **`ci.yml` HAS NO `push:` TRIGGER ANY MORE.** Re-adding it does not make CI safer, it adds a second full-price E2E per merge; the two-line revert is spelled out in the `on:` block. **This change cannot be tested on a branch** — `deployment_status` and `repository_dispatch` only ever run the DEFAULT BRANCH's copy of a workflow, so the proof is the first master deploy after merge: if no `E2E (Playwright)` run appears within ~20 min of it, revert.
