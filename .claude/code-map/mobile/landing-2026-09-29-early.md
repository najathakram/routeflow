# Landing batch 2026-09-29 — early (mobile + web side, through #2134)

Docs-only bookkeeping (Option B) for the mobile- and web-facing PRs of the same batch, one bullet
per PR, each grepped in the merged tree at HEAD (`d8ad4de32`). This file also covers WEB
(`apps/web`). API/packages/tooling PRs are in [../api/landing-2026-09-29-early.md](../api/landing-2026-09-29-early.md).

- **#2134 (closes #2055) price suffix names the line's own unit, two more mobile sites, `d8ad4de32`:** `apps/mobile/lib/invoice-line-display.ts` gains `priceUnitSuffix(item, upb)` (`upb > 1` -> ` / <noun> of <upb>` via `invoiceLineUnitNoun`, else `unitLabel`, else `unit`, else ""), independent of any screen's `isBoxed` gate. `components/edit-items/DraftItemCard.tsx` (both price lines) uses it; `app/(driver)/route/stop/[stopId]/adjust.tsx` `AdjustLineRow` uses `invoiceLineUnitNoun(li)` instead of the hardcoded word "box". Specs: `invoice-line-display.test.ts`, `price-unit-suffix-wiring.test.ts`.
- **#2287 (closes #2173) buyer bell switches seller with no stale frame or mis-keyed write, `49998caf1`:** web. `apps/web/lib/hooks/useBuyerNotifications.ts` keeps the list and its storage slot in ONE state (`bell: {key, list}`), reloading during render when `buyerNotificationsKey(buyerId, tenantId)` changes (after a `hydrated` flag, so the first client render matches the server), so no frame paints the previous seller's notices. `add` persists an incoming socket event under the STORED active seller's slot (`getStoredActiveSeller`), joining the visible list only when that list is that slot; mark-read/clear write to the on-screen list's own key. Never split list and key across two states again. Spec: `useBuyerNotifications.test.ts`.
- **#2729 (closes #2727) bound the buyer cart + catalog qty input width, `00a13d14a`:** `apps/mobile/lib/row-layout.ts` `QTY_INPUT_WIDTH` gains `buyerCart: 44` and `buyerCatalog: 44`; `app/(customer)/orders/cart.tsx` and `app/(customer)/(tabs)/catalog.tsx` `qtyInputReset` set a definite `width` + `flexShrink: 0` (on react-native-web a TextInput's intrinsic ~177px width ballooned the stepper and squeezed the name column at 390; `minWidth` is only a floor). Spec: `row-layout.test.ts`.
- **#2066 (#1799 D-05) pack/unit labels on the PO detail item rows, `143dd1534`:** `linePack(line, livePack)` (stored `packSize` wins over the live product's pack) moved to `packages/pricing/src/pricing.ts`; `apps/web/app/(dashboard)/inventory/_components/purchase-orders-shared.ts` re-exports it under the old name. `apps/mobile/app/(operator)/purchase-orders/[id].tsx` labels Ordered/Received/Remaining with `unitsLabel(qty, upb)` for a boxed line, bare number otherwise (never append the live product's `unit`). The PO LIST endpoint lacks `product.unitsPerBox`, so this is detail-screen only. `packages/pricing/src/no-mirrors-linepack.spec.ts` fails on a local copy. Specs: `po-detail-item-pack.test.ts`, `po-detail-unit-display-wiring.test.ts`, `pricing.spec.ts`.
