## Stack & shape

Multi-tenant delivery / route-management SaaS. **npm workspaces + Turbo** monorepo.

- **API** — [`apps/api`](api.md): NestJS 11, Prisma 7 + PostgreSQL, Redis (Socket.io), JWT auth.
  Everything tenant-scoped. Jest specs.
- **Web** — [`apps/web`](web.md): Next.js 14 App Router. The **golden reference** for flows/DTOs.
  Radix + Tailwind, TanStack Query, Zustand, RHF + zod. Playwright e2e.
- **Mobile** — [`apps/mobile`](mobile.md): Expo 55 / RN 0.83, expo-router, multi-role. Mirrors
  web's API/DTOs/flows; only UI differs. Jest (pure-logic).
- **Packages** — [`packages`](packages.md): `types`, `ui`, `config`, `eslint-config`,
  `typescript-config`.
- **Deploy**: Railway via per-app Docker. `CMD = node dist/main.js` only — never auto-migrate.

## Entry points

- **api** → `apps/api/src/main.ts` — boots Nest on `:3000`, global prefix `/api/v1`, health
  `GET /api/v1/health`. Runs from compiled `dist/main.js` (watch mode is broken).
- **web** → `apps/web/app/layout.tsx` (+ `app/providers.tsx`) — `next dev` on `:3001`.
- **mobile** → `apps/mobile/app/_layout.tsx` — `expo start`. Deep-link scheme `routeflow://`.

- **Verification layers (2026-08-20):** 4 layers, mapped feature-by-feature in `docs/testing/verification-matrix.md`. (1) `npm run verify` — unit/lint/types. (2) `npm run post-deploy-check` — read-only authenticated probe. (3) **`npm run feature-smoke` (`scripts/feature-smoke.mjs`) — WRITE-path smoke on the approved test tenant only** (`assertTestTenant` at startup; provisions its own `E2E-SMOKE-*` fixtures; cleanup in `finally`; S1–S9 cover boxed proration, no-wipe PATCH, stock-count lifecycle, variant assign, supplier allocation + credit drain, bulk mark-paid, estimate guards, orders?productId + revenue-weighted invariant, uploads fail-closed, statement routes). ⚠️ Its S4 credit-drain bill is deliberately left as DRAFT history — voiding/deleting a bill that drew SupplierCredit REFUNDS the draw and re-poisons the next run. (4) Playwright e2e — specs 13–16 (`boxed-order-entry`, `pack-size-prompt`, `stock-count-ui`, `variant-split-ui`) are read-only-or-cancel BY DESIGN: they build UI state, assert, then Escape/discard/cancel, so repeated runs never mutate the tenant. `npm run regression` chains 1→2→3. nightly.yml runs them but is DORMANT while the repo is private (public-only scheduled workflows).
