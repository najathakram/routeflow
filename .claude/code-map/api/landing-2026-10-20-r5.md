## Money: JSON null, NaN, script guard (rows 591/602/603/593, SA-816)

- `common/validators/optional-not-null.ts` (NEW) `IsOptionalNotNull(opts?)`: `@IsOptional()` that skips only `undefined`, so a JSON `null` money field is a 400 (never `Number(null)` = $0). Applied across about 35 money DTOs (invoice, order, sale, counter-sale, return, estimate, PO, recurring, promotion, customer, expense, onboarding, tracked-category, addon-sku); `PartialType` Update DTOs redeclare the field. Allow-list of deliberate clears lives in `common/money-dto-null.spec.ts`.
- `common/money-invariants.util.ts`: `finiteStoredMoney(value, label)`, `finiteStoredLevy(row, label)`: a stored non-finite amount is a 400 `MONEY_INVARIANT`, never a silent $0 or a verbatim copy. Used by `credit-notes/credit-notes.service.ts`, `returns/inline-returns-quote.service.ts`, `orders/carry-line-category.ts` and the invoice paths (`common/stored-nonfinite-money.spec.ts`).
- `scripts/lib/assert-finite-money.cjs` (+ `.d.cts`, repo root) `assertFiniteMoney(value, label)`: every script that binds money into raw SQL calls it. Pin: `common/script-money-writers.spec.ts` derives NUMERIC columns from the schema folder and requires the import-and-call or an `EXEMPT` entry with a true reason (shrink-only, L-202). `scripts/repair-f03.mjs`, `repair-f10-reopen-damage.mjs` now call it; `apps/api/scripts/stamp-addon-comp.mjs` is exempt (binds no money).
- `bookkeeping/bookkeeping.service.ts`, `audit/audit-actions.constant.ts`, `sales-agents/sales-agents.controller.ts`: small money-null and audit-action changes.
