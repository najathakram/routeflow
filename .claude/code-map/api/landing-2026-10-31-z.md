- `customers/price-history-comparison.ts`: new `COMPARE_MIN_CUSTOMERS_NO_SALES_ACCESS = 3` and `compareMinCustomers(role, deniedGroups)`: 0 for TENANT_ADMIN and SUPER_ADMIN, 0 for an OPERATOR unless both ORDERS and FINANCE are denied (then 3); fails closed (an OPERATOR with no denials passed in, or any other or missing role, gets 3). `comparisonLines(sales, plots, minBuyers)` now draws every month that has a sale (line 2 with one other sale; line 3 also a month of only this customer's sales); an empty month is absent, never filled.

- Response shape (`packages/types/api/price-history.ts`): `PriceHistoryAggregate.newestMonth` is new; `aggregate` is null when no other customer bought the product (or below the OPERATOR floor).
