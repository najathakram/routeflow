## #3977 `31dcb0c10c` one price-edit answer at every site that takes a typed price (SA-1034 PR7)

Rule: one helper answers "may this principal type a line price", the denied groups read live and the permissions MODE applied; the till stays live. A custom (no product, no `systemKind`) line is a typed price, so authoring one needs the same right. A copy (merge, template run, convert, resubmitted unchanged line) is not authoring and never asks.

- `auth/permissions/operator-denied-groups.ts` (new, moved from `orders/counter-sale/till-permission.guard.ts`): `operatorDeniedGroups(prisma, user)` = groups an OPERATOR is denied (all groups minus held; no row = all denied, fail closed); `[]` for any other role with no read. `till-permission.guard.ts`, `customers/customer-price-history.controller.ts` and `selling-restrictions/selling-restrictions.service.ts` now import it from here.
- `auth/permissions/price-edit-answer.ts` (new): `roleMayEditPrice(role)`, `mayEditPrice(role, deniedGroups)` (the only two `staffMay(…, "EDIT_LINE_PRICE", …)` calls), `priceEditReported(role, heldGroups, allGroups, mode)` (the MODE-applied answer the web is told: `live` applies denials, anything else is the role-only answer).
- `auth/permissions/price-edit.ts` (new): `priceEditAllowedFor(prisma, user | null | undefined, site): Promise<boolean>`. No principal or a role that may not edit (DRIVER, CUSTOMER, SUPER_ADMIN): `false`, no read. `live`: the enforced answer, a failed deny-list read throws. `shadow`: role-only answer, one `would-deny groups=… handler=<site> tenant=…` warn when enforcement would have refused; a failed read allows by role and logs an error. Callers compute it once per request, before any transaction.
- `auth/permissions/operator-permissions.service.ts`: `effective()` result gains `priceEditAllowed` (from `priceEditReported`). `packages/types/api/permissions.ts`: `MyPermissions.priceEditAllowed: boolean` (web reads this, never a role).
- `orders/staff-override.ts`: new `packPriceMovesBaseline(product, tier, typedPrice, layer?)` (yes/no, same baseline as `decideTierOverride`, never throws, a reason is not required); new `isCustomPricedLine(line)` and `assertCustomPricesAllowed(lines, priceEditAllowed)` (same 403 `PRICE_EDIT_NOT_PERMITTED` as `assertPriceEditAllowed`, thrown before any write); the pack baseline is shared through a private `packBaseline`.
