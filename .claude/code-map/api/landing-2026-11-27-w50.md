Pin `batch-import-tenant.pin.spec.ts` with a count-pinned `NOT_ENTRY_POINTS`.
- **#4551 mail wall for test businesses (W-1464 PR-A; `5b9e9f125d`).** `email/recipient-wall.ts` is checked at both `email.service.ts` public sends (`send`, `sendPlatform`); both and the account-mail wrappers take a required `tenantId` (about 59 files pass it).
