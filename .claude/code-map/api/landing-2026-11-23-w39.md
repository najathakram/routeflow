## Vendor bills: a PO bill line in its own unit (#4405 `83a8ceb260`, #4413 `ad9ff7137d`)

- **#4405 SA-1207 P2a, check X in `vendor-bills/po-bill-match.ts`.** QTY is judged in pieces; line MONEY is judged in the line's own unit (`ownQty` x `ownUnitCost` on `BillLinePieces`), never through a 4-decimal piece cost. `lineWithinPoLine` passes a line when any PO line of the product allows it: the larger of pieces x `unitCost` and `totalCost` x pieces / ordered, plus the one-cent `PO_LINE_TOLERANCE`. The whole bill is held to the larger of the two PO sums. R-005 stays a hard 409 with the same codes; no stored figure changes. `vendor-bills.service.ts` fills `ownQty` / `ownUnitCost` in the line mapper that calls `lineInventoryDelta`.
- **#4405 `packages/pricing/src/po-bill-lines.ts` (new, exported from `index.ts`).** `billLinesFromPO` fills bill lines in the PO's stored pack (a case line when whole boxes reproduce the stored total, else one lot); `billQuantitiesFromPO`; `lotUnitLabel`; `poLinesNotPrefilled` (a fractional quantity on a boxed line is never prefilled, SA-1207 A3; returns the `poItemId` or index for "Enter this line by hand").
- **#4413 SA-1207 S2b, one reader and one writer for a bill line's own unit.** `packages/pricing/src/bill-line-unit.ts`: `billLineUnit` (kind `case | piece | lot | unstated`), `billLineLocked`. `vendor-bills/bill-item-data.ts`: `billItemData`, `billItemPack`, `NO_IDENTITY`. `vendor-bills/bill-line-identity.ts`: `resolveCreateIdentities` (mints the group id server-side and proves each group), `resolveEditIdentities`, `carryStoredIdentities` (edits pair rows by id and carry `unitLabel`, `familyProductId`, `familyGroupId` from the stored row), `assertWholeLotReceive`. A lot or split child changes `unitCost` only (409 `SPLIT_LINE_LOCKED`); a duplicate line id is `DUPLICATE_LINE_ID`; a part-received lot is `LOT_QTY_NOT_WHOLE`. New error codes in `common/api-error-codes.ts` and `packages/types/api/error-codes.ts`. `bill-line-pack.ts` and `pack-size-gate.ts` adjusted; mobile `lib/vendor-bill-scan.ts` follows. No migration; `billLinesTotal` unchanged. Census: `vendor-bills/bill-line-unit.census.spec.ts`.
