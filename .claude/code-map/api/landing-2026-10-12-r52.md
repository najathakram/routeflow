- `invoices/finalize-order-recompute.ts` NEW `bumpRevisionIfSaleMoved(db, tenantId, order, totals, touched)` (fires on `touched.lines` or a moved fee; `touched` is an out-param of `finalizeOrderRecompute`). `invoices/order-backsync-lines.ts` NEW `SALE_NEUTRAL_COLUMNS` (`invoicedQty`, `categoryTaxAmount`) via `orderLineUnchanged(..., ignore)`. `recomputeOrderFromInvoices` takes `lockOrderRow` first.
