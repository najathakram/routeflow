## #3750 `f4a819bf4` the operator permission row is honoured on the till and office payment paths (W-870)
- `auth/permissions/staff-capabilities.ts`: `staffMay(role, action, deniedGroups)` lost its `= []` default, so `deniedGroups` is REQUIRED at every call site (a request caller passes `operatorDeniedGroups(prisma, user)`, a caller with no principal passes `[]`). "Permission row" = an OPERATOR's denied permission groups (ORDERS, PRICING, ...) now decide the capability, where before most sites judged the role alone.
- `orders/counter-sale/till-permission.guard.ts`: new `assertStaffMay(prisma, user, action)` (live denied groups, else 403 `PERMISSION_DENIED` naming the capability's group) and `posModeDeniedGroups(prisma, user, requested)` (reads denials only for an explicit PICKUP). `counter-sale-void.service.ts` now uses `assertStaffMay(..., "VOID_SALE")`; `counter-sale.service.ts` computes `priceEditAllowed` over `operatorDeniedGroups`.
- `invoices/counter-payment-guard.ts`: new `counterPay.voidScope(prisma, invoiceId, user, applies?)` and `TillUser = PermissionPrincipal`; a till invoice runs the `VOID_SALE` check, and a till invoice with no principal fails closed (403). An ordinary invoice is never judged.
- `invoices/invoices.service.ts`: `voidInvoice(id, user)`, `voidPayment`, `deletePayment` and `setCheckStatus(..., by)` take the principal; `updatePayment(invoiceId, paymentId, dto, opts)` now requires `opts: RefCtx` (was optional `RefOpts`), with `RefCtx = RefOpts & { user: PermissionPrincipal }` added in `invoices/payment-edit-ref.ts`. `invoices.controller.ts` passes `@CurrentUser()` into all five routes.
- `orders/fulfil-path-resolver.ts`: `FulfilPathInput` and `FulfilCaller` gain required `deniedGroups`; `fulfilCaller(user, deniedGroups)` and `assertFulfilPathOffered(deps, requested, role, deniedGroups)` take it, so POS mode (`USE_POS_MODE`) honours the denials. Callers updated: `orders.controller.ts`, `orders/order-lifecycle.ts`, `orders/merge-candidates.ts`, `orders/default-sale-fulfilment.ts` and `buyer/buyer.controller.ts` (buyer and system callers pass `[]`).
- `selling-restrictions/selling-restrictions.service.ts`: private `withDeniedGroups(params, breached)` builds the override principal; an OPERATOR's denials are read once, only when a breach exists, and an OPERATOR with no `sub` is denied every group (`ALL_PERMISSION_GROUPS`, fail closed).
