## Infra hardening — SEC-2 (2026-07-16, branch deferred-items-validation)

- **F12-003** — api + web run as non-root `node`. `apps/api/Dockerfile` runner adds `su-exec` + `apps/api/docker-entrypoint.sh` (runs as root, `mkdir -p /data/uploads` + `chown -R node:node /data`, then `exec su-exec node "$@"`) so the mounted uploads volume stays writable; `apps/web/Dockerfile` just sets `USER node` (no writable volume). Both validated by a branch deploy.
- **F12-002 (CLOSED — PR-1, `imp-03a`, 2026-09-03)** — both boot-time DDL paths are gone: `apps/api/src/main.ts`'s `runStartupMigration()` (`ALTER TABLE … ADD COLUMN IF NOT EXISTS`) and `platform-admin/platform-config.service.ts`'s `onModuleInit` (`CREATE TABLE IF NOT EXISTS "PlatformConfig"`/`"AiUsageEvent"` + index) are both deleted, not flagged — 2026-09-03 prod evidence (`migrate status`: 23 applied, none pending/failed; `migrate diff`: empty, exit 0) proved the live schema already matched the datamodel. Replacement: a read-only drift gate, `apps/api/scripts/schema-drift.mjs` (+ `scripts/lib/railway-db-url.mjs`), run post-deploy via `prod-migrate.mjs` and in `db-migrations.yml`; static tripwire `src/common/no-runtime-ddl.spec.ts` + `platform-admin/platform-config.no-ddl.spec.ts` fail the build if raw DDL returns.
- **F12-004 (RESOLVED 2026-08-28)** — every install is now lockfile-exact `npm ci`: web/mobile Dockerfiles + all 9 workflow install blocks (ci.yml ×5, nightly ×2, post-deploy ×2). The old blocker was NOT the win32-swc EBADPLATFORM (modern npm skips foreign-platform optional deps cleanly) but a single incoherent edge — apps/mobile `jest ^30.3.0` vs the root override pin `jest 30.2.0` — which npm 10's override-unaware `ci` validator exploded into ~97 phantom-30.5.0 errors (npm 11 tolerated it, which is why it "worked locally"). Fix: mobile range relaxed to `^30.2.0` + lock regenerated with npm@10.8.2 (only dead nested dupes removed, zero version floats). Web Dockerfile's react@18.3.1 root-swap stays a deliberate exact-pinned `npm install --force --no-save` (npm ci can't add packages).
- **F12-001 (mostly moot)** — the socket.io stack already resolves patched `ws@8.21.0` (advisory ≤8.20.1); the critical `websocket-driver@0.7.4` is a transitive of `firebase-admin` with NO upstream patched version (not override-fixable).
