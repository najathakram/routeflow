# Api landing, window 52 (master `f932dabcc8`)

Paths under `apps/api/src/` unless they start with another root. Window 52: #4335 `f932dabcc8`. The buyer-facing parts (web portal, mobile) are in the web landing note of the same date.

- **#4335 delivered-line floor and merge lock (W-946r, SA-1149, B1355).** `orders/delivered-line-lock.ts`:
  - `assertQtyNotBelowDelivered(deliveredQty, heldQty, nextQty)` throws 409 `LINE_ALREADY_DELIVERED` only when the next quantity is below BOTH the delivered quantity and the line's held quantity, so a note edit restating an over-delivered line is not a cut. It is judged on the FINAL stored quantity in the line's own unit (after `normalizeBoxesPieces`). Fixed sentence `DELIVERED_LINE_BELOW_MESSAGE`.
  - `ORDER_HAS_NO_LIVE_DELIVERED_LINE` (a Prisma where-fragment) and its JS twin `isLiveDeliveredLine`: an order holding a live (non-CANCELLED) line with `deliveredQty > 0` is never a merge winner or loser, because a merge folds by replace and would lose the delivered stamp (B1167). One fragment read by every `forMerge` search and both branches of `mergeEligibleWhere` (`orders/merge-lock-recheck.ts`); spread only where no other `lineItems` key exists, otherwise inside an `AND`.
  - `orders/order-sweep.ts`: the pending-sweep count uses `mergeEligibleWhere("auto")`, the same predicate as the fold (`readMergeGroup`), so a delivered-line order is in neither (closes B1355).
  - `orders/unit-line-edit.ts` takes `flooredDelivered` (the delivered floor per line id from the one `heldAtBookedFloor` read in `updateOrderItems`, required: no second read) and applies the floor to every non-substitute line; `orders/orders.service.ts` passes it.
  - `orders/delivered-stamp.ts`: the carry sums per product (delivered, held, next) over the lines not surviving the edit, skipping CANCELLED ones, and refuses a recreated total below the floor, so an omitted delivered product counts as zero. Off the carry (the order is not DELIVERED, or rode a route stop) a replace-all that would delete a live delivered line is refused 409 `ORDER_EDIT_DELIVERED_LINES` (`DELIVERED_LINES_REPLACED_MESSAGE`). A legacy row with quantity below delivered stays as it is (B1050).
  - `common/api-error-codes.ts` and `packages/types/api/error-codes.ts`: `ORDER_EDIT_DELIVERED_LINES`.
  - Pins: `orders/delivered-line-lock.qty-floor.spec.ts`, `delivered-line-lock.qty-floor.structure.spec.ts`, `w946r-qty-floor.db.spec.ts`, `w946r-merge-delivered.db.spec.ts`, `delivered-stamp.spec.ts`, `merge-lock-recheck.spec.ts`.
