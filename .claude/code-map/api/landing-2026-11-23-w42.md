- **#4444 receipt tag on the payments list (M1-03, SA-1211 BF-6; `7b91efe3da`).** `invoices/payment-receipt-group.ts` gains `readListReceipts(prisma, rows)`: tags the CONFIRMED (PAID, non-credit-use) rows of each OFFICE_GROUP check on one list page with that check's figures (`PaymentListReceipt`: key, number, total, invoices in receipt order). Pinned by `invoices/payment-list-receipts.spec.ts`.
