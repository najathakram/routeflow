## #4175 `84c9ae766d` account links slice 2: one claim per link (row 633, SA-1096)

Rule: a one-time link is taken by one conditional write, so only one caller wins it, and any writer that changes an account's status, soft delete, role, email or admin flag ends its live links in the same transaction.
- `auth/link-token-revocation.ts` (`revokeUserLinkTokens`, `revokeBuyerLinkTokens`): the one helper to end links; called from `users/users.service.ts`, `customers/customers.service.ts`, `billing/billing-cron.service.ts` (seat-cap sweep), `buyer/{buyer-admin,buyer-auth,buyer-merge,buyer}.service.ts`.

## #4130 `8f4a144273` first pack asks how to read stock (W-867 F01, SA-946, SA-961 R1, SA-1093)

Rule: when a product gets its first pack (blank or 1 becomes N above 1) and the save holds stock or cost, the server refuses with 409 `PACK_READING_REQUIRED` until the save says Boxes (stock, reorder level and quantity x N; average and standard cost / N; each open lot x N and cost / N; prices do not move) or Pieces (only the pack is set). Zero stock and zero cost: no question.
- `products/pack-intro.ts`, `pack-intro-apply.ts`, `pack-intro-cost-check.ts`, `pack-intro-undo.ts`: the decision, the apply through `applyStockMovements` (the one stock writer, inside `products.service.ts` `update()`'s transaction, audit row `product.pack_introduced` in `audit/audit-actions.constant.ts`), the cost check, the undo. `products/dto/update-product.dto.ts` carries the reading. Import: `import/import-pack-reading.ts`, `import-columns.ts`, `import.service.ts` read as pieces and count products with cost above price / N in the dry run.
- SA-1093 rules: void of a bill after Boxes takes out the bill's quantity in today's pieces (`vendor-bills/vendor-bills.service.ts`); revert to draft and PO re-apply refuse with 409 `RECEIVED_BEFORE_PACK`; return cancels take out quantity x factor from the return's own movement (`returns/{returns.service,inline-returns.service,returns-restock.util,returns-restock-pieces}.ts`); Boxes is refused with `PRODUCT_IN_OPEN_COUNT` on an open count (count lock before stock lock, `inventory/inventory.service.ts`) and with `PACK_OPEN_LINES` while an open order holds a line with its own unit or box split (status set `CANCEL_CREDITS_FROM` in `orders/order-status-transitions.ts`). Error codes in `common/api-error-codes.ts` and `packages/types/api/error-codes.ts`.
- Tests: `products/pack-intro.{spec,pin.spec}.ts`, `pack-intro-cost-check.spec.ts`, `pack-intro-undo.pin.spec.ts`, `pack-intro.db.spec.ts`, `pack-intro-orders.db.spec.ts`, `inventory/inventory.po-edit.db.spec.ts`, `vendor-bills/vendor-bills.void-after-pack.db.spec.ts`, `returns/return-cancel-after-pack.db.spec.ts` (C-6d passes with the amended #4130), `import/import-pack-reading.spec.ts`, `stock-lot-readers.pin.spec.ts` (P-1: every row that negates a quantity has a decision on a list).
