- **#4489 one open Checkout Session slot per business (W-1338 PR-1, SA-1267; `6c71fa8c62`).** `src/billing/open-checkout-session.ts` (new): `openCheckoutSession(deps, { tenantId, customerId, surface, readOffer })` runs under the `tenant-price` advisory lock (`underSlotLock`; a lock timeout or an unreachable lock is the coded 503 `CHECKOUT_SLOT_UNAVAILABLE`). It lists the business's Stripe sessions (`metadata.tenantId`, 2-day window, 5 pages of 100, a list failure fails closed), refuses a complete-but-unapplied one (409 `CHECKOUT_PAYMENT_IN_PROGRESS`), reads the terms only under the lock (`SlotOfferReader`, no value comes from the caller), reuses an open hosted session whose `termsHash` matches, else expires the others and creates one with idempotency key `rf-slot-<hash of tenant, customer, terms, newest session id>`. Also `expireOpenCheckoutSessions` (callers hold the lock across their write), `readOpenLink`, `cancelOpenLink` (409 `CHECKOUT_LINK_NOT_EXPIRED`). URLs are re-read from Stripe, never stored, logged or put in an error. `billing/billing.service.ts`: the checkout start now only gates (read-only `checkoutAddonLines` and `checkoutPriceData`) and hands the slot `checkoutOffer(...)` (private, called only by the slot); `getOpenLink` and `cancelOpenLink` delegate. `billing/subscription-mutation.service.ts`: `subscribe` and `downgrade` now run under `underTenantPriceLock` (`subscribeLocked`, `downgradeLocked`), and subscribe, upgrade and downgrade call `expireOpenCheckoutSessions` first; `platform-admin/platform-admin.service.ts` calls it on a plan move and before a fee change's first Stripe write. Routes (`platform-admin/platform-admin.controller.ts`): `GET tenants/:id/billing/open-link`, `POST tenants/:id/billing/open-link/cancel` (both `UNGUARDED` in `auth/permissions/permission-map.pinned.ts`; the controller is platform-admin guarded). Three codes in `common/api-error-codes.ts` and `packages/types/api/error-codes.ts`. Pins: `billing/billing.open-checkout-slot.spec.ts`, `billing/open-checkout-session.inventory.pin.spec.ts`, `billing/checkout-session-policy.pin.spec.ts`, `platform-admin/platform-admin.open-link.controller.spec.ts`.
