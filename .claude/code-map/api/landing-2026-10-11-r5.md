## Mode switches (both ship dark; unknown value = dark)

- `BILLING_PAUSE_MODE` = `off | dark | enforced` via `dunning-config.ts` `billingPauseMode(env)`; `dunningEmailsFor(mode) -> "legacy_failed_payment" | "milestones"` is THE switch for which email path may tell a tenant about an unpaid invoice (`off`/`dark`: master's failed-payment mail only; `enforced`: the d0/d3/d6/final/paused series replaces it). `dark` stamps and logs, never changes a status.
- `SELLER_READ_ONLY_BUYER_GATE` = `dark | enforced` via `buyer/guards/buyer-seller-context.guard.ts` `sellerReadOnlyBuyerGate(env)`; separate from the pause mode because a lapsed trial is READ_ONLY too. Both documented in `apps/api/.env.example`.
