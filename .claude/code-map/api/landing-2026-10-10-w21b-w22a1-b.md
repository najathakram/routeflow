## Protected-tenant guard for scripts (row 195, SA-756r)

Rule: a live-capable writer cannot touch a protected tenant (arm `paying`, `stripe-linked`, or `env-listed` via `PROTECTED_TENANT_SLUGS`) unless the operator names its id (`--allow-protected <tenantId>`, repeatable), passes `--backup-taken`, and types `ALLOW PROTECTED <tenantId>` at a real TTY. Ids and counts only; slugs are never printed. Retired flags `--allow-paying-tenant`, `--confirm-paying` are refused (`refuseRetiredFlags`).
