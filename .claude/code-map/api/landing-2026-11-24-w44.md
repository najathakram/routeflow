# API landing, window 44 (master `0762a57ee4`, PRs #4463, #4423)

Both PRs are root tooling (`scripts/`, `.husky/`), outside `apps/api`; they are filed here because the `scripts/` rows of the api area live in this part. Facts read in the merged diffs and the files at `0762a57ee4`. The web half (#4419) is in `web/landing-2026-11-24-w44.md`. Trust the code over this note.

- **#4463 pre-push verify stops at the first failing step (SA-1251 F3; `c16e47995c`).** One switch, `RF_VERIFY_FAIL_FAST=1`, exported by `.husky/pre-push`; unset (CI, a bare `npm run verify`) every planned call runs as before. `scripts/lib/verify-fail-fast.mjs`: `isFailFast`, `phase0Call` (lint runs before queueing for the heavy slot, after a `PHASE0_PREBUILD` of `./packages/*` builds; skipped for workspaces in `LINT_IN_SLOT`, now `@routeflow/api`, and when a caller already holds the slot), `failureReport` (names the failed turbo tasks from the run summary and prints the last `TAIL_LINES` 40 lines), `notRunLines`. `scripts/verify-turbo.mjs`: `buildTurboFlags(concurrency, summarize)` adds `--summarize` in fail-fast mode, `executePlan(calls, runCall, ran, failFast)` breaks at the first non-zero call, `splitJest` is on in fail-fast mode. Self-test: `scripts/verify-turbo.self-test.mjs`.
- **#4423 flag edited test assertions for review (`1fa7b84d04`).** `scripts/review-test-edits.mjs --base <sha> --head <sha> [--json]` lists EXISTING test assertions a diff removed or changed (added tests are ignored; only lines removed from the base side count). Test files are `*.spec.ts`, `*.test.ts(x)`, `*.test.mjs`; `testRanges` finds each `it`/`test` block by paren depth, `classify` marks assertion lines and skips trivial ones, `findEdits(base, head)` returns the hits. Exit 1 when any are found, 2 on a crash or bad usage. Tests: `scripts/review-test-edits.test.mjs`, wired into `npm run verify` as `node --test scripts/review-test-edits.test.mjs`. The two `.claude/skills/` edits in the PR (fleet-lead `TEMPLATES.md`, future-proof `SKILL.md`) are skill text, not mapped.
