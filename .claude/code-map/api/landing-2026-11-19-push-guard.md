# Api landing, push leak guard (#4363, master `a250e9194c`)

Merged 2026-11-19 as `a250e9194c` (PR head `92d7bbb7c2`); every path below was re-checked on that master. Root tooling, no `apps/api/src` behaviour change; paths are repo-relative. Brand-neutral by design: the patterns are not in git.

- **#4363 fail-closed push guard (W-1232; hooks only, no migration, no env var except the launch switch).**
  - `.husky/pre-push`: after reading git's stdin once, the first step runs `node scripts/leak-check.mjs --hook` (refuses first when the checker file is missing); it runs before the trunk check, the `SKIP_VERIFY` hatch and verify, so a skip cannot bypass it.
  - `scripts/leak-check.mjs`: modes `--hook`, `--range <a..b>`, `--text-file` or `--stdin` (a PR title, body or squash text), `--tree`. It scans added lines, file names, commit messages, author identity and ref names; output names shas, paths and counts, never matched text, and withholds a path that git quoted or that matches. Exit 0 clean, 1 hit, 2 usage, patterns file missing or empty, or a failed git call.
  - `scripts/lib/leak-patterns.mjs`: loads `<git-common-dir>/info/leak-patterns` (untracked, one clone-wide file): case-insensitive regexes, `commit:<sha>` sentinel lines, `path:<prefix>` lines; matches UTF-8 and UTF-16 text.
  - A private line of work stays off GitHub: any push carrying a commit to a private ref is refused, its own ref included (deleting it is allowed), and another branch carrying its commits not on `origin/master` is refused; a single launch-day switch lifts the private checks (owner ruling 2026-11-19).
  - Tests: `scripts/leak-check.self-test.mjs` (throwaway repos, neutral fixture pattern, 153 checks, fast mode 40), `apps/api/src/common/leak-check-self-test-script.spec.ts` (runs it in Jest); the two hook-fixture specs `apps/api/src/common/pre-push-trunk-script.spec.ts` and `skip-verify-audit-script.spec.ts` now copy the checker and its lib, write a dummy patterns file and pin the missing-checker refusal; `scripts/registry-root.self-test.mjs` lists the self-test in FIXTURES.
  - Lanes: `leak-check-self-test-script.spec.ts` runs in the repo-truth lane like `bugs-self-test-script.spec.ts` (`apps/api/jest.repo-truth.config.js`, the `(bugs|leak-check)-self-test-script` ignore pattern in `jest.scripts.config.js`, `src/common/script-spec-lane.spec.ts`); `turbo.json` hashes `.husky/pre-push` into the repo-truth inputs.
  - Docs: `docs/runbooks/push-leak-guards.md` (one-time setup per clone, retirement). A clone without the patterns file is refused at pre-push; CI never runs the hook.
