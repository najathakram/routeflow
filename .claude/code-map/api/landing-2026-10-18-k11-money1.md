## #3476: one Stripe gate for CANCELLED and tenant delete

- `platform-admin/stripe-termination-gate.ts` (NEW) `stripeGateBeforeTermination(...)` and refusal builders `cancelSubscriptionFirstRefusal`, `stripeAccountMismatchRefusal`, `stripeSubscriptionOwnerMismatchRefusal(...)`, `stripeNotConfiguredRefusal`, `stripeUnconfirmedRefusal` (retryable `CONCURRENT_UPDATE`, reason `STRIPE_UNCONFIRMED`), `tenantChangedRefusal`; `StripeGateDeps`. Runs BEFORE any transaction: a plain read of the stored subscription id, then one Stripe read with a short timeout and ONE retry (404 resolves null; 401 or a bad key is STRIPE_NOT_CONFIGURED at once). The returned subscription must be this tenant's (stored customer id, `metadata.tenantId`) and is judged for ownership BEFORE its status; no stored id is allowed with no Stripe call; a terminal status is allowed.
- `platform-admin/platform-admin.service.ts` private `stripeGateBeforeTermination(id, adminId)` delegates to it for status to CANCELLED and tenant delete (about 110 lines of inline logic removed).
