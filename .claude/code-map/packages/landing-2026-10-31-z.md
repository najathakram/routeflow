## #4040 `378db04b39` a tier price above Retail stops turning into a manual price (B316, SA-1072)

- `packages/pricing/src/pricing.ts`: `isUpsellLine(line)` (MANUAL only) is replaced by `isAboveListLine({ unitPrice, originalPrice })`: true when `originalPrice` is set and `unitPrice` exceeds it, whatever the `priceType` (a staff upsell or a tier above Retail stored as SPECIAL). It is the one rule for hiding the lower base from a customer. `isStickyUpsell(remembered, list)` is unchanged; callers now pass `stickyPrice`.
- `packages/pricing/src/show-original-price.ts` `showOriginalPrice` returns false for any line `isAboveListLine` accepts (was MANUAL only); a saving on SPECIAL, DISCOUNTED, PROMO or an adjusted MANUAL still strikes the original.
- `packages/types/api/orders.ts` `CustomerPriceHistory[productId]` gains `stickyPrice: number | null` (the newest remembered line's price when staff chose it, MANUAL, else null); `lastPrice` is what "Last:" shows and never prices a line above list.
- Tests: `packages/pricing/src/pricing.spec.ts`.
