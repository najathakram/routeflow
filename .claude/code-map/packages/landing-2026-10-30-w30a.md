## #3994 `6ec72d515` SA-1029 per-piece price beside a pack line
- New `packages/pricing/src/per-base-unit.ts`, re-exported from `packages/pricing/src/index.ts`: `perBaseUnitPrice(line, baseUnitLabel)` returns `{ price, unit }` = `round4(unitPrice / unitsPerBox)` (null for a loose line, a non-integer or <=1 pack, a negative or non-finite price, no `productId`, or a `systemKind` / `compositionMode` line); unit word from `unitWords({ baseUnitLabel }).base.short.one`. Also `basePriceText(n)` (min 2, max 4 decimals, "$2.00", "$2.0005"), `formatPerBaseUnitPrice(p)` ("$2.00/pc"), `baseUnitSuffix(perBaseUnit?)` (the word after "/", "pc" when absent), const `DEFAULT_BASE_UNIT_WORD`, interface `PerBaseUnitLine`, and alias `PerBaseUnitPrice` (= `PerBaseUnit`). Display only: never summed or multiplied back.
- `packages/types/api/invoices.ts`: new `PerBaseUnit` ({ price: number; unit: string }), the one declaration. `packages/types/api/buyer.ts`: `BuyerInvoiceItem.perBaseUnit?: PerBaseUnit | null`.
- Importers: web staff invoice, buyer portal invoice, `InvoiceDisplayRows` and `lib/api/invoices.ts`; api `invoices/invoice-display-unit.ts`, `invoice-email-payload.ts`, `invoice-pdf-item.ts`, `invoice-pdf-template.tsx` and `email/email.service.ts`. `formatUnitPrice4` (web-local) is gone; `basePriceText` replaces it.
