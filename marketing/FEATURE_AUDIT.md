# RouteFlow Feature Readiness Audit

Phase 1 of the founding-wholesaler trifold brochure workflow. Date: 2026-08-19.
Branch: `claude/routeflow-marketing-strategy-rj6x49`, head `2abfb4e`.

Method: features were enumerated from four directions and cross-checked, per the workflow
brief: API controllers and services (`apps/api/src/*`), wired UI surfaces (web
`apps/web/app/*`, mobile `apps/mobile/app/*`), Prisma models and migrations
(`apps/api/prisma/`), and plan or add-on gates (`billing` feature flags, tenant add-ons).
The evidence base is the code-verified inventory built in this session (three parallel
audits of API, web, and mobile against the code map at `.claude/code-map/`), plus the
local test run below. A feature counts as SHIP only when it is reachable end to end in a
shipped UI, not just an endpoint.

Statuses: SHIP (works end to end, brochure-eligible), PARTIAL (works with a stated
limitation, eligible only with wording that survives the limitation), NOT READY (never
appears in marketing).

## True proof points (countable, code-verifiable)

- Tenant isolation enforced in the data layer on every query, plus Postgres row-level
  security as a second wall.
- 5 roles: super admin, tenant admin, operator, driver, customer, plus a separate buyer
  identity that cannot cross into staff tokens.
- 21 IRS Schedule-C expense categories seeded out of the box.
- About 20 finance reports, every one exportable to CSV.
- 4 regulated levy types: excise per unit, per volume, container deposit, percent of sale.
- Texas Comptroller 12-column filing format, plus CA CDTFA, CA ABC, and CalRecycle
  templates, generated from an immutable sales ledger.
- Licence checks run at 4 points: order, edit, invoice, delivery.
- Up to 5 price tiers per product plus per-customer negotiated prices.
- Up to 10 pages per supplier-invoice scan, with duplicate detection before you pay twice.
- 10 failed logins lock an account for 15 minutes; secrets encrypted with AES-256-GCM.
- Nightly production database backups with automated restore verification.
- Interface in English and Spanish.
