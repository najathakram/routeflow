04 · Motion & Delight
The rules

Three speeds, one spring. 120ms press (every button, chip and checkbox squishes on tap) · 240ms enter (cards rise in with a 36ms stagger, toasts slide from the right) · 400ms celebrate (confetti burst on the moments that matter: order delivered, run completed, payment received, never on routine clicks). Numbers count up on dashboards; the bell shakes on new notifications; a scan sweeps green across the input and flashes the touched row so the operator trusts it landed. All of it collapses to zero under prefers-reduced-motion.

Spring: cubic-bezier(.3, 1.4, .5, 1) · Ease-out: cubic-bezier(.2, .9, .3, 1) · No infinite loops except the 2.2s urgent pulse.
