# RouteFlow Marketing Package

A complete, code-verified marketing foundation for RouteFlow, written against the product as it
actually works today (verified 2026-08-19 against the live codebase, not the roadmap).

| Doc                                                        | What it is                                                                                                                                                            |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [01-product-documentation.md](01-product-documentation.md) | Detailed documentation of RouteFlow: every shipped capability in business language, plus an explicit "not ready — do not market" list.                                |
| [02-marketing-strategy.md](02-marketing-strategy.md)       | The strategy: ICP, personas, positioning, message house, claim discipline, competition, pricing, go-to-market motion, channels, 90-day plan, KPIs.                    |
| [03-content-playbook.md](03-content-playbook.md)           | The content: social video scripts, post series, a 4-week calendar, full draft copy for a tri-fold brochure and two print flyers, a demo script, and website fix list. |

## Ground rules baked into every doc

1. **Marketing only what works.** The featured pillars are the ones confirmed solid in code:
   orders, invoicing & payments, inventory, regulated-product compliance, expenses & bookkeeping,
   and the buyer portal. Delivery-day execution (POD, at-door payment) is a supporting story.
   Vehicle/GPS tracking, third-party integrations, and messaging are **not** marketed — they are
   stubs or roadmap (see the do-not-claim list in doc 01 §15 and doc 02 §5).
2. **No fabricated proof.** No invented stats, testimonials, or customer names. Placeholders are
   marked `[PLACEHOLDER]` and must be replaced with measured results before use.
3. **No live-client references.** All examples use fictional businesses (Acme Distribution,
   Marisol's Corner Store, etc.), per the repo's test-tenant policy.

## How to use this package

- Review the **Assumptions** section at the top of doc 02 first and correct anything wrong
  (pricing, geography, launch timing) — the rest of the package inherits those answers.
- Doc 03's print copy is written to be pasted into a design tool as-is; bracketed placeholders
  are the only parts that need real values (domain, QR codes, phone).
- The website fix list in doc 03 §9 should be actioned **before** any paid traffic is sent to the
  existing marketing site — several current claims are ahead of the product.
