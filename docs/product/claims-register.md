# Claims register

_The source of truth for every sentence we say about the product in public: the website, the sales
deck, sales copy, emails and the app store listing. One row per claim, each with the code or test
that proves it._

- **Base:** `master` at `d977b00d4b`, read on 2026-11-24. Paths and line numbers are at that sha.
- **Method:** a read of the source and the tests, not a run. Each row cites the code path that decides
  it and, where one exists, the test that pins it. Nothing here was checked against the production
  database or the production environment variables; rows that depend on those say so.
- **Kept current:** any PR that changes user-visible behavior updates the row it affects in the same PR.
  A sentence about the product does not ship anywhere public unless its row here says `live`.

## Status words

| Status               | Means                                                                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `live`               | Built and reachable for a new account today.                                                                                              |
| `live behind a flag` | Built, but only on when a named flag, add-on, setting or switch is on. The row names it.                                                  |
| `partly true`        | Some of the sentence is true. The row says which part is not.                                                                             |
| `false`              | The sentence is wrong today for the plan or case the row names.                                                                           |
| `not built`          | The code was read and the capability is not there.                                                                                        |
| `UNKNOWN`            | Not settled. A keyword scan that found nothing is `UNKNOWN`, never `not built`. The row lists what was searched and what would settle it. |

## C. Gate inventory (at `d977b00d4b`)

How a gate decides:

- **Add-on gates** (`@RequireAddon`) read `apps/api/src/billing/feature-registry.ts` (re-exported by
  `addon-gate-registry.ts`). `dark` lets every account through and logs; `enforced` refuses without the add-on.
- **Plan-flag gates** (`@RequirePlanFlag`) read the plan's flags. Flags in `DARK_PLAN_FLAGS`
  (`apps/api/src/billing/plan-flag-policy.ts:13`) let every account through **unless** the environment
  variable `PLAN_FLAG_ENFORCEMENT` is `"on"`. Five of them (`PREPIN_DARK_FLAGS`, `:37`) stay open even then.
